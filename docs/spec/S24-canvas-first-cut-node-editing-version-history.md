## 产品边界

- 画布是用户手工创建节点和连线形成的专业工作流，不是 Agent 规划结果。
- 不提供全画布 Agent 命令栏、自动铺图、计划确认或费用确认。点击“运行节点”即授权当前动作。
- 对话/套图产物送入画布后作为可见素材节点挂载，不改写原产物修改权；画布下游产物归画布。
- 3a 只承诺单节点运行和指令编辑，不承诺整链运行、画布模板发布或多人实时协作。

## 上游契约实施门禁

`05` 已冻结 `canvases.revision`、版本化 `graph_json` 和稳定 node/edge/input-slot/mention 结构；`06` 已冻结 canvas CRUD/save/mount/compile、SSE scope 和错误码；单节点 run 复用 `04` 的 workflow/task/attempt。

S24 开工时通过新 migration 增加 `05` 标注的 3a 前向字段，并按 `06` 实现 DTO/Controller/Service。不得修改 S02 已提交迁移，也不得由前端自行扩展 payload、graph schema 或运行状态；若性能门禁要求调整最大图规模，只改运营配置默认值并复审，不改变显式边/附件/`@` 语义。

## 当前模块范围

包含 C01 画布列表、C02 编辑器 3a 状态、空白画布、节点/边 CRUD、上传/资产挂载、文本/图片/视频节点、单选/多选、上下文工具条、节点下方面板、附件与局部 `@`、单节点生成/编辑、候选和版本、自动保存/冲突、移动只读。

不包含整链运行、画布导出、发布模板，归 S25；不包含 UGC 市场，归阶段 4。

## C01 画布列表

- 按最近编辑分组，支持搜索、新建空白、从已开放模板创建、复制、重命名、删除。
- 卡片只展示缩略图、标题、更新时间、节点数和运行摘要；不展示“AI 已规划”等文案。
- 删除展示画布内节点/产物影响；原始对话/套图产物不随画布删除。
- 空态直接提供“新建空白画布”和从商品/产物进入的说明，不做营销 hero。

## C02 编辑器布局

C02 使用全屏专业工作区，隐藏普通业务主导航；顶栏提供返回 C01/来源产物的明确入口，左侧第一列只保留画布工具。不得同时堆叠全局主导航、会话栏和画布工具栏。

| 区域       | 3a 固定能力                                                                    |
| ---------- | ------------------------------------------------------------------------------ |
| 顶栏       | 返回、标题、保存状态、撤销/重做、任务日志、积分；3b 导出/发布/整链运行暂不显示 |
| 左侧工具栏 | 选择、手形平移、文本、图片、视频、便签、上传、资产选择；使用图标和 tooltip     |
| 中央画布   | 节点/边、框选、拖拽、缩放、适应视图、小地图、空白区添加菜单                    |
| 节点上方   | 单选上下文工具条；多选只显示共同操作，不叠加多套工具条                         |
| 节点下方   | 当前单选可执行节点的附件、prompt、参数、费用和单节点执行面板                   |
| 右侧抽屉   | 版本历史/对比、任务日志、资产选择；不作为节点主参数入口                        |

左侧工具栏和画布控件尺寸稳定，不随节点内容或状态变化位移。节点下方面板通过 viewport portal/NodeToolbar 等机制保持可读；空间不足时自动翻转到左/右，但必须继续贴近所属节点。

## 画布基础交互

- 单击选择，Shift 多选，空白拖拽框选；空格/手形平移，滚轮缩放，适应视图，撤销/重做，复制/粘贴，Delete 删除。
- 双击空白区打开添加节点菜单；拖入文件创建素材节点；从工具栏创建空文本/图片/视频生成节点。
- 边连接时提供合法/非法反馈；客户端提前校验，服务端保存和运行时再次校验。
- 删除有下游的节点前展示影响数量；删除边不删除任一节点。
- 多选允许移动、复制、删除、对齐和分布；3a 不做跨节点批量改模型/参数。
- 处理中允许继续搭图；画布编辑和后台任务互不锁死。

## 节点共同契约

- 每个节点含稳定 `node_id`、类型、名称、输入/输出 handle、主体内容、用户状态、当前版本和权限态。
- 用户状态只显示：未配置、可运行、排队中、生成中、检查中、成功、失败/需处理。
- 素材节点与生成节点必须视觉区分：素材节点可替换/连线，不出现“重新生成”；生成节点保留参数、候选和版本。
- 隔离产物只显示复核占位，禁止预览、下载、引用为输入；只读/无权限节点不显示收费动作。
- 节点内部输入、滑块、播放器使用 `nodrag`/等价隔离，不能误拖节点。

## 三类节点

| 节点 | 允许输入               | 节点主体                             | 下方面板                                                      |
| ---- | ---------------------- | ------------------------------------ | ------------------------------------------------------------- |
| 文本 | 0-N 文本/图片分析输入  | 原文、生成文本或摘要；文本可就地编辑 | 附件、prompt、文本模型、输出格式、费用、运行                  |
| 图片 | 0-N 文本/图片参考      | 素材或当前结果、尺寸、候选/版本角标  | 附件角色、prompt、图片模型、比例/尺寸/数量、费用、运行/编辑   |
| 视频 | 0-N 文本/图片/视频参考 | 素材或封面/播放器、时长、版本        | 首尾帧/参考排序、prompt、视频模型、比例/时长/数量、费用、运行 |

便签只用于说明，不参与 DAG、报价和执行。音频素材按 PRD 能力矩阵作为输入节点占位，3a 不新增音频生成节点。

## 选中节点上方工具条

- 通用：预览、复制、删除、更多。
- 文本：编辑、复制文本；后置操作不显示灰色占位。
- 图片：分析、去背景、指令编辑、下载、存资产、替换；聚焦/蒙版只在对应阶段和模型准入后出现。
- 视频：预览、下载、替换、设首/尾帧；提取帧只在能力准入后出现。
- 指令编辑点击后复用节点下方面板并切换“编辑”模式，不打开脱离附件和费用的轻量弹窗。
- 多选只显示对齐、分布、复制、删除等共享动作。

## 节点下方上下文面板

面板只属于当前单选节点，不读取全画布：

1. **有序附件条**：显示所有输入边及源节点缩略图、角色、版本、就绪状态、预览、排序和移除。
2. **prompt**：自然语言主输入，支持当前附件域内 `@`；编辑模式提示填写改变项与保持项。
3. **参数**：模型、比例/尺寸/时长、质量、数量，只显示已准入模型支持项。
4. **报价**：参数/附件/源版本变化即使旧报价失效；显示总积分、有效期和退款/未知回执说明。
5. **执行**：生成、重新生成或指令编辑；动作名称和计价档必须明确分开。

## 附件、边与 `@` 硬契约

- 手工新增 node/edge 使用 `crypto.randomUUID()` 生成规范小写 UUIDv4；服务端保存/编译校验格式和图内唯一性，服务端创建的挂载/复制节点也遵循同一规则。
- 合法上游边建立后，上游自动进入目标节点附件条。
- 从附件条添加上传文件/资产时，先在目标节点左侧创建可见素材节点，再建边；不得产生隐藏附件。
- 移除附件只删除对应边，不删除上游节点。删除源节点前展示所有受影响下游。
- 多输入可拖动排序；顺序持久化到 edge/input slot，不按画布坐标推断。
- `@` 只列当前附件条，不搜索全画布、其他节点、会话或资产库。
- mention 持久化 edge/source node/artifact ID；graph node ID 与 `node_versions.node_id` 使用同一个 UUIDv4 值，显示序号可变，绑定对象不可漂移。
- 边删除、源版本回退、源节点隔离/无权限/未完成时，mention 标为失效并阻止报价提交。
- 连接类型、数量和必填输入由能力矩阵校验；非法边不能靠前端 JSON 绕过。
- 上游运行中可连线，但下游执行时必须等待就绪或要求用户明确选择已完成版本，禁止静默用旧输出。

## 单节点运行与收费

- 运行前编译当前目标节点、显式上游、附件角色/顺序、参数、模型和权限；不扫描无边节点。
- 仍走 `run_quote -> 生成动作证据 -> reservation + workflow_run -> settlement`；点击运行后服务端报价、核对并预留，不弹第二个确认框。
- 单节点运行快照固定输入版本；运行期间上游变化不改写已提交任务。
- 重新生成沿用参数创建新候选；指令编辑使用当前结果和新指令，走编辑计价；两者不合并。
- accepted/outcome_unknown 后不自动重投；用户动作按 `04` 明确重试规则。

## 候选与版本

- 生成/编辑/替换均创建 `node_versions`；节点主体显示当前选定版本和候选缩略图。
- 版本抽屉显示来源动作、时间、参数/费用摘要和产物状态；最多 20 个可用版本以 PRD 为准。
- 回退只切换当前选定版本，不删除后续版本；回退后下游引用显示源版本变化，重新运行前必须重编译。
- 两版本并排对比同步缩放；隔离/已删除版本只显示元数据和状态。
- 失败保留最后成功版本，但节点状态必须提示最近一次失败，避免看似成功。

## 保存、刷新和冲突

- 本地即时更新，防抖保存完整图快照/差异；服务端以 revision 做 compare-and-set。
- 顶栏明确：保存中、已保存、离线、冲突。刷新从服务端图快照恢复，任务从 workflow/task 快照恢复。
- 多标签 revision 冲突时停止覆盖，提供“加载远端版本”或“复制当前为副本”；3a 不自动合并图。
- 离线可保留未保存本地草稿，但禁止报价/运行；恢复后先解决 revision 再提交。
- 不持久化 `processing=true` 等前端瞬态为运行真相。

## 移动端与可访问性

- 移动端 C02 为只读：平移/缩放、节点预览、任务状态、版本查看和下载；不显示拖线、批量编排和参数编辑。
- 键盘可完成选择节点、打开工具条、移动焦点、删除确认和打开任务日志；画布之外提供任务文字列表。
- 颜色不是唯一状态表达；节点/边状态带图标或文字，toolbar 按钮有 tooltip 和可访问名称。

## API 面

按 `06` §4.1 实现画布列表/创建/详情/重命名/复制/删除、带 revision 的保存、artifact mount、节点版本列表/选择和 compile；单节点收费复用 run quote/submit，进度复用 canvas/workflow SSE scope。所有写操作带用户边界、幂等键或 revision；任何产物读取/下载重新鉴权。

## 测试标准

- 实现并通过 `pnpm validate:canvas-mount`：对话/套图产物挂载、R1-R5、下游归属、跨用户拒绝。
- 组件测试：三类节点、toolbar、下方面板、附件排序/删除、局部 `@`、失效引用、只读/隔离。
- API/并发测试：revision 冲突、重复保存、重复运行、报价过期、权限变化、上游版本变化。
- Worker/账本测试：单节点生成/编辑、accepted/outcome_unknown、明确重试、版本写入和 ledger replay。
- Playwright：手工建文本/图片/视频节点 -> 连线 -> 附件出现 -> `@` -> 单节点生成 -> 编辑 -> 回退/对比 -> 刷新恢复。
- 性能门禁：冻结目标节点/边规模，在该规模下拖拽、框选、缩放和状态更新不得出现不可接受卡顿；未达标不得用降低功能正确性掩盖。
- 桌面/移动截图与像素检查：面板不遮挡节点/顶栏，长中文状态不溢出，移动端不出现可误触编辑控件。
