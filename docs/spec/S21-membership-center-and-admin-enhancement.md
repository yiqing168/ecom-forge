## 当前模块范围

包含头像上传/更换及安全处理、会员权益只读页面、后台手工授予/撤销会员、运营申诉队列、模型/积分/风险账户增强。

不包含真实支付，支付后续 S26。

## 交付面

| 交付面   | 要求                                                                                   |
| -------- | -------------------------------------------------------------------------------------- |
| 前端/UI  | 头像编辑、“我的权益”只读页面和运营后台增强；不显示公开开通、充值、价格或“即将上线”按钮 |

## 业务规则

- 会员权益展示不得承诺未接入的支付能力。
- 头像只能引用当前用户已完成检查且可见的图片资产；更换只更新用户引用，不绕过 S10 的对象访问、内容审核和删除保留规则。
- 2A 的“会员占位”仅指数据库权益结构和后台手工授予能力，供内测白名单使用；前端只展示用户当前真实权益，不提供任何公开购买入口。
- 充值、支付、订阅、价格展示和公开开通 UI 全部归后续支付 SPEC，不得在 S21 预埋可点击入口。
- 管理员手工授予必须提交 tier、到期时间和原因，写入 membership 来源/授予人，并记录变更前后审计；撤销同样适用。
- 管理员操作必须最小权限和审计。
- 会员并发、积分赠送仅按配置生效。

## 验收清单

- [ ] 用户只能看到当前真实权益；管理员可按权限手工授予或撤销并留下审计。
- [ ] 用户可安全更换头像，跨用户、隔离、删除和处理中资产不能绑定。
- [ ] 运营后台可批量处理申诉队列。
- [ ] 高风险操作有审计。
- [ ] 配置变更可追踪。
