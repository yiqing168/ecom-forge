# 全站 UI 出图提示词

| 项   | 内容                                                                        |
| ---- | --------------------------------------------------------------------------- |
| 用途 | 供 GPT Image、Stitch 等工具生成全站高保真 UI 视觉稿                         |
| 范围 | 21 个普通用户页面族：A01-A10、B01-B09、C01-C02；独立管理台另行设计          |
| 基础 | `00-stitch-full-site-ui-design-plan.md`、`01-full-site-screen-flow-spec.md` |

视觉 token 只以 `stitch-design-system.md` 为准；本文是中文出图提示词和评审对照，不得覆盖设计系统中的尺寸、字体、颜色、圆角与产品壳规格。

## 使用方法

1. 每次先粘贴“全局固定提示词”。
2. 再追加一个“页面提示词”。一次只生成一个页面或一个关键状态。
3. 图片生成结果只用于视觉、布局和组件层级评审；正式实现使用真实 React/HTML 组件，不把整张图片作为网页背景。
4. 任一结果出现后台 KPI、营销首页、画布优先、英文主界面、不可用的小字、虚构交易确认或未开放功能，直接判废。

## 全局固定提示词

```text
设计 Ecom Forge，一款面向中国电商卖家的 AI 图片创作产品。输出 1440×900 桌面端高保真产品界面，中文为主，达到已上线商业产品的完成度。

产品视觉：不是后台管理台、不是营销 Landing Page、不是内容社区、不是画布优先产品。它是一个专注于“商品图 + 一句指令 -> 快速完成创作”的工作台。创意任务点击生成后由 Brain 解析图片张数并直接进入积分核对；电商任务只把必要商品事实确认放在对话流内，不显示费用卡、执行模式、数量控件或当次积分上限。参考成熟中国 AI 创作产品的输入优先、轻量导航、真实商品视觉和克制工作区，但不要复制任何竞品品牌、Logo、文案、像素布局或截图。

统一普通产品壳：左侧 128px 紧凑导航，顶部为品牌；每个入口均为图标加 12px 中文文字。1A 的创作、商品、资产、作品、任务依次排列，阶段 2 追加批量、套图、发现，阶段 3 追加画布，账户始终在底部。全站稿必须画出画布入口，单独评审 1A 页面时才隐藏后续入口。选中态使用窄靛蓝指示条和浅色背景。顶部栏 64px，只放当前上下文；登录后右侧可放积分、全局任务、帮助、账号，站内通知随 S16 激活，访客只放帮助和登录。不要宽后台侧栏、顶部横向菜单、KPI、活动倒计时、会员营销。

视觉系统：暖白背景 #F7F7F5，白色工作表面，墨黑文字 #171A1F，靛蓝 #2F49DF 只用于主操作，珊瑚色 #E56A54 用于异常，青绿 #087B75 用于信息/成功辅助，琥珀 #B56A18 只用于积分与费用。中文字体使用 Noto Sans SC、PingFang SC 或 Microsoft YaHei。主标题 32-40px，正文以 16px 为基准且不低于 15px，操作标签至少 14px；12-13px 只用于非关键元数据。文字清晰、不重叠、不缩成微小灰字。最大圆角 8px，使用细边框和轻微层次，不使用紫色/蓝色渐变、玻璃拟态、光球、霓虹、3D 装饰、过大圆角或大量悬浮卡片。

商品图片必须明亮、真实、可检查，包含服装、鞋包、家居、美妆等真实电商品类；不使用模糊气氛图。页面要有真实交互暗示，但不显示内部状态枚举、思维链、tool JSON、Provider 原始错误、完整 prompt、签名 URL 或数据库字段。
```

## 第一组：1A

### A01 登录/注册弹层

```text
在 A04 访客态新会话页面上展示“点击开始创作后”的登录弹层，不要生成独立登录网站。背景必须仍看得到用户的创作输入、商品附件、左侧窄导航和开始创作按钮，使用低透明度遮罩，说明登录后可回到原草稿。

居中白色弹层宽约 480px，标题“登录后开始创作”，说明“你的指令和附件会保留，登录完成后可继续发送”。只放 1A 已裁决能力：邮箱、密码、忘记密码、登录并继续、注册账号、邀请码或白名单提示、用户协议和隐私政策勾选、右上角关闭按钮。预留不跳动的行内错误区域。不要手机号、微信、二维码、第三方登录、营销插画。登录成功回原输入，但不自动提交。
```

### A02 注册与邀请

```text
在 A04 访客态上保持同一个 A01 登录弹层，并切换为“创建内测账号”注册态，不生成独立页面。字段为邮箱、密码、邀请码或白名单邮箱、协议确认；清楚显示内测资格状态。主按钮“注册并发送验证码”。包括“当前无法完成注册，请检查邀请码和邮箱是否正确”和邮件暂不可用两个不引起弹层跳动的行内错误位置，不暴露邀请码内部原因。关闭后仍保留 A04 原草稿。
```

### A03 邮箱验证与找回

```text
在 A04 访客态上的同一个 A01 弹层中展示邮箱验证与找回状态，不生成第三个独立页面。主状态为“输入邮箱验证码”，显示已发送到部分脱敏邮箱、6 位数字 OTP 输入、10 分钟有效期、60 秒重发倒计时、返回登录入口。输入支持粘贴、自动前进和退格回退；预留验证码错误/过期/5 次耗尽、ticket 失效、限流和邮件暂不可用的固定行内状态区。验证成功后关闭弹层并回到原创作草稿，不自动发送。
```

### A04 访客新会话首页

```text
设计 Ecom Forge 首屏，访客态新会话。核心动作只有一个：描述创意或上传参考图，写一句需求，点击“开始创作”。点击后才会打开登录弹层；本页不能显示报价、确认、计划、任务面板、画布或聊天记录。

顶部左侧“新会话”，右侧“帮助”“登录”。主区标题“今天想做点什么？”，副文案“上传参考图，直接告诉我你想要的效果”。下方是遵循 `stitch-design-system.md` 所定 960-1060px 宽度区间、约 280px 高的大型白色 Composer：已有输入“把这件白色连衣裙做成电商白底主图，保留衣服颜色和版型”；底部有添加附件、一张连衣裙缩略图、加号、@引用附件、智能生图 Agent/智能视频 Agent、Skill 和“开始创作”按钮。选智能生图 Agent 后显示比例/数量；选智能视频 Agent 后显示 720P/1080P、比例、时长/数量。数量控件提供常用值和自定义正整数输入，不只提供固定候选；指令中的“两张”“生成 6 张/条”等明确数量会同步到控件与确认摘要。控件分组自然，Composer 是第一视觉中心；不要放固定“选择商品”控件。

下方放三个精致快捷入口：白底精修、人像焕新、照片意象重绘；入口由服务端 catalog 驱动并等同于显式选择对应 primary。再下方放“从示例开始创作”，仅四张高质量商品或创意示例，每项有短中文场景标签。示例是创作起点，不是社区卡片或素材市场。
```

### A04 活跃对话与直接生成

```text
设计 A04 已登录的活跃对话状态。左侧普通紧凑导航旁可展开 280px 会话历史栏，包含“新会话”、搜索、今天/昨天分组的中文会话标题，保持低视觉权重。中央是自然的聊天工作区：用户上传白色连衣裙并说“做两张白底主图”，Agent 先给出紧凑的结构化解析与商品事实卡；用户确认商品身份、关键颜色、Logo/包装标识和可见文字后，直接显示“正在核对积分”，随后显示“正在生成 2 张白底主图”和结果。不得插入费用确认卡。

不要出现计划确认、费用确认卡、执行模式、数量控件、逐步确认或复杂独立表单。图片张数由 Brain 从用户原话解析；Compiler 报价后只在进度中显示预计积分，余额不足或数量越界就地提示且不调用 Provider。电商任务只显示必要商品事实卡。结果卡含大图预览、候选切换、继续改图、下载、存入资产、关联商品；底部固定 Composer 仍可继续输入。右侧任务/产物只提供一个可打开的轻量入口，不常驻成为第三列后台。
```

### A05 商品列表

```text
设计商品列表页面。主区标题“商品”，副标题说明可按商品名或 SKU 管理创作素材。顶部是一行搜索、状态筛选和主按钮“新建商品”。内容采用精致的商品行或两列紧凑卡片：每项有主图、商品名、SKU、最近创作时间、作品数量和进入箭头；不使用后台大表格或销量数据。展示服装、鞋包、家居、美妆等商品。包含无商品空态：引导“从商品图开始创建”，并有上传商品图按钮。
```

### A06 商品详情

```text
设计商品详情页面，展示一个商品的完整创作上下文。顶部有商品主图、商品名称、SKU 和“开始创作”主按钮；主体使用清晰分区而不是仪表盘：商品信息与已确认事实、商品素材、关联作品、最近任务、成本摘要。事实区显示颜色、主体、可见文字等可编辑标签，不显示底层 JSON。右侧不常驻长面板。视觉上像高品质商品工作档案，而非 CRM 表单。
```

### A07 我的资产

```text
设计 1A 资产库页面。顶部为“资产”、搜索、筛选和“上传素材”按钮，不显示文件夹入口。主区使用有呼吸感的媒体网格，图片缩略图足够大，按素材类型和最近使用显示。每项有文件名、用途标签和更多操作；选中时可出现底部操作条“加入本次输入”。包含上传中进度、缩略图失败、隔离不可用三种轻量状态。不要变成传统文件管理器密集表格。文件夹管理随 S18 另行设计。
```

### A08 我的作品

```text
设计“我的作品”页面。顶部有按商品/SKU、来源、状态筛选，主区以高质量结果网格展示生成图片，商品优先而不是社交瀑布流。每项包含成品图、商品名/SKU、生成时间、保真提示；悬停操作为预览、下载、继续改图、存入资产。选中一张作品时可打开全屏预览抽屉。隔离作品要有明确“等待复核，暂不可访问”的状态，不显示原图。
```

### A09 任务中心

```text
设计用户任务中心，保持非后台化。标题“任务”，顶部有状态筛选、商品/SKU 搜索。主区是清晰的任务时间线列表：缩略图、用户视角状态文案、商品、提交时间、预计/实际积分、结果入口。展示正在生成、已完成、本次生成未完成、结果复核中、已退款、失败等自然中文状态，不展示内部状态枚举。单项详情使用右侧抽屉，包含进度、结果、取消或明确重试入口。
```

### A10 账户与积分

```text
设计账户与积分页面。顶部是一张克制的余额摘要区：可用积分、冻结积分、最近变动和“查看流水”，不能做会员营销。下方使用两个清晰 Tab：“积分流水”“账户设置”。流水按日期分组，显示自然中文原因、金额、余额和可申诉入口；不暴露 ledger 事件名。账户设置只包含注册昵称只读、昵称首字头像、邮箱验证/密码安全和退出；不提供头像上传、通知偏好、会员或购买占位。余额不足状态使用温和珊瑚提示和返回创作入口。
```

独立管理台不使用 A11 或普通站 `/admin`。O01-O12/O13 的视觉与交互以 S14A/S14B 已冻结的 `apps/admin` 设计系统和权限契约为准。

## 第二组：1B-2B

### B01 批量任务列表

```text
设计批量任务列表，面向电商卖家一次处理多个商品/SKU。顶部有“新建批量”主按钮、状态/商品/时间筛选。内容显示批量名称、SKU 数量、完成/失败数量、总积分、创建时间和进入箭头。每项使用进度条和少量商品缩略图表达进度，不做后台报表。空态强调“选择多个商品，统一生成”。
```

### B02 新建批量

```text
设计新建批量工作台，采用清晰的线性步骤但不要做冗长向导：选择商品/SKU -> 上传或复用素材 -> 统一创作要求 -> 检查条目与预计积分 -> 点击开始批量创作。左侧小型步骤导航，中央当前步骤工作面，右侧仅保留轻量选择摘要。页面重点是商品批量选择、字段映射和统一主图要求。最后一步显示 SKU 数、产物数、预计总积分、失败退还和部分失败说明，底部主按钮“开始批量创作”；点击即提交，不弹费用确认框。
```

### B03 批量详情

```text
设计批量详情页。顶部显示批量名、整体进度、商品数量、下载全部和导出 CSV。主区用分组列表展示每个 SKU 的结果：成功图片预览、生成中、失败可重试、部分完成。不要做难读的大宽表；用商品缩略图、状态和操作组成可扫描的行。包含“仅重试失败项”和“打包下载”操作。
```

### B04 公开分享

```text
设计公开分享页，去掉登录后的侧导航，使用简洁品牌页头。页面展示单个高质量成品图或一组作品，包含商品类别、有限的创作说明、作者公开昵称、发布时间和“我也要做”按钮。内容居中、干净、以作品为主，不能复刻编辑器。对于已撤回/已过期，显示明确的不可访问状态和返回创作入口。
```

### B05 发现

```text
设计模板与参考图库发现页。顶部为“发现”、搜索、分类筛选（主图、详情页、风格、行业）和收藏入口。主区是高品质、可扫描的模板/参考媒体网格；每张图明确标示授权、类型和收藏操作。页面有探索感但不是社交广场，没有榜单、直播、活动 Banner。用户进入详情后可作为参考启动新创作。
```

### B06 模板/参考详情

```text
设计模板或参考图详情页。左侧大幅媒体预览，右侧是标题、作者/授权、适用行业、版本、收藏和说明。核心动作是“用作参考创作”或“用于套图”，不是直接获得原作者修改权。若需要解锁，展示清晰价格和权益，余额不足时有恢复出口。内容要像专业创作素材详情，不做电商商品详情页。
```

### B07 我的权益

```text
设计只读的“我的权益”页面。展示当前有效权益、可用额度、当前奖励活动带来的赠送说明和权益生效时间；没有支付按钮、套餐定价、即将上线占位或会员营销。页面克制、透明，入口可返回账户或创作。
```

### B08 套图列表

```text
设计套图列表，按商品/SKU 管理整套主图和详情页任务。顶部有“新建套图”、商品搜索和状态筛选。主区每项展示商品主图、SKU、已生成图片数、套图状态、最近更新时间和结果预览条。空态引导“选择一个商品，开始整套出图”。不要出现未开放的画布功能。
```

### B09 套图工作台

```text
设计商品/SKU 驱动的套图工作台，参考成熟电商出图工具的效率结构。左侧紧凑步骤：商品与事实、规格、卖点、图片类型、附加项、预计积分；中央是当前设置工作面；右侧是始终可见但轻量的套图预览和图片数量摘要。商品主图和事实信息先行，平台/比例/语言/卖点结构化填写，图片类型支持“智能推荐”和“自定义”。最后一步显示全部图片类型、附加项和预计积分，唯一主按钮“生成套图”，点击即提交且不弹确认框。同时预留平台规范普通警告、高风险证据确认和内容安全硬拦截三种位置。不要独立报价页、聊天页、营销页或混乱大表单。
```

## 第三组：3a/3b

### C01 画布列表

```text
设计画布列表，仍使用普通产品壳。顶部是“画布”、搜索、排序和“新建画布”按钮。内容为最近编辑的画布缩略图列表，显示名称、最后编辑时间、节点数量和更多操作。可从作品“送入画布”进入；空态提供新建空白画布和从模板创建。不要把画布列表误做成 A04 对话首页。
```

### C02 画布编辑器

```text
设计专业全屏无限画布编辑器，独立于普通产品壳。深色或中性深灰专业工作区可以使用，但要克制，不使用霓虹。顶部仅有返回、画布名称、保存状态、撤销/重做、任务日志、积分、导出。左侧垂直工具栏只有选择、平移、添加文本节点、添加图片节点、添加视频节点、上传、资产。

中央画布展示文本、图片、视频节点和清晰连接线。选中一个图片节点时：节点上方出现紧凑操作条（预览、复制、删除、更多）；节点下方出现就地输入面板，包含已连接上游附件、prompt 输入、@ 当前附件引用、模型/比例参数、预计积分、运行按钮。点击运行即提交当前节点动作，服务端编译、核对并预留后执行；整链运行同样使用单一主动作，不做 Agent 计划确认或费用确认。手动添加附件必须表现为画布上真实的上游素材节点和连线。不能把整张画布自动规划成 Agent 流程，不能把全画布内容放进 @ 候选。
```

## 代表性 Overlay 提示词

### 附件与资产选择

```text
在 A04 上打开右侧抽屉式“添加附件”选择器。左侧是文件夹，主区是资产缩略图网格，顶部有上传、搜索、筛选。选中的图片进入底部“加入本次输入”栏；确认后回到 Composer，并只作为当前输入的 @ 候选。包含上传中、上传失败、隔离不可选状态。
```

### 作品大图预览

```text
在 A08 上打开作品全屏预览。深色遮罩，中央以最大可查看尺寸展示单张商品生成图，右侧或底部有候选切换、下载、继续改图、存入资产、关联商品、关闭。保真 warning/unknown 用温和信息提示呈现，不覆盖图片主体。
```

### 画布节点添加菜单

```text
在 C02 空白画布上打开添加节点菜单。菜单是紧凑浮层，提供文本、图片、视频、上传素材、从资产库添加，带清晰图标与短说明；不出现复杂模板市场、Agent 自动规划或不可用功能。
```
