## 正反核验

正向：更新共享 token 和既有视觉组件能让正式页面、弹窗与状态一致，无需重复搭建业务页面。

反向：改变菜单或将真实数据换成 mock 超出本次范围；仅改 CSS 不能声明模型质量改善；调整导航宽度会牵涉多处固定定位。因此不改导航宽度和功能结构，只改变视觉呈现。

## 会话切换修复

`/workspace/session` 使用共享布局承载工作台，子路由只表示当前会话或新对话。切换会话、前进/后退及进入新对话时，左侧会话栏保持挂载，保留搜索、已加载分页和滚动位置，不因会话 ID 变化重新请求列表。首次进入、搜索、提交和显式重载仍请求服务端，重命名/删除仍按服务端回执更新列表；不引入浏览器持久化会话数据或跨账户全局缓存。

正向：利用 Next.js 布局生命周期稳定列表，无需改 API、交易或菜单。反向：共享挂载不能共享不同会话的聊天、输入附件、模型或设计师；右侧内容按会话重置，过期详情、发送结果和 SSE 回调不得污染新会话。回归覆盖桌面/移动、搜索/分页/滚动、当前选中、历史导航、新对话和迟到失败。离开会话区后不承诺保留列表；刷新页面仍重新鉴权和加载。
