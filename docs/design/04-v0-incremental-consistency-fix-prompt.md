# v0 全站原型增量修正指令

> 将本文件完整发送给已经根据 `03-v0-full-site-ui-interaction-prompt.md` 生成项目的 v0。不要重新创建项目；在当前代码和路由上增量修正。

## 修改原则

保留现有 Next.js App Router、React、TypeScript、Tailwind、shadcn/Radix、mock 数据、路由和已经完成的页面。不要推倒重做，不要删除现有可用交互。本轮只修正导航、费用流程、设计 token、Overlay 和画布细节。

## 1. 左侧导航必须显示画布

这是全站演示，默认开启阶段 2、阶段 3 feature flag。桌面左侧 128px 图标加文字导航从上到下固定为：

1. 创作 `/`
2. 商品 `/products`
3. 资产 `/assets`
4. 作品 `/artifacts`
5. 任务 `/tasks`
6. 批量 `/batches`
7. 套图 `/suites`
8. 发现 `/discover`
9. 画布 `/canvases`，使用 lucide `Workflow` 图标

账户 `/account` 固定在导航底部。点击“画布”进入 C01；C01 右上角必须有“新建画布”。点击后选择空白画布或模板，创建并进入 `/canvases/:id`。进入编辑器后隐藏普通主导航，但顶栏左侧必须有“返回画布列表”。

主导航“创作”始终进入 `/` 创作首页。会话栏“新对话”和商品、作品、参考图等上下文创作动作进入 `/workspace/session/new`；从首页或空白会话发送后创建并进入 `/workspace/session/:id`。不得把这三类入口重新合并成同一个路由。

## 2. 统一设计 token

- 顶部工具栏固定 64px。
- A04 展开的会话历史栏固定 280px。
- 页面主标题 32-40px，分区标题 20-24px，正文以 16px 为基准且不低于 15px，操作标签至少 14px；12-13px 只用于非关键元数据。
- 左导航 128px，每项显示图标和 12px 中文文字，最大圆角 8px；背景/文字为 `#F7F7F5`/`#171A1F`，主动作靛蓝 `#2F49DF`，异常珊瑚 `#E56A54`，信息/成功辅助青绿 `#087B75`，积分与费用琥珀 `#B56A18`。

## 3. 修正 Agent 生成与积分体验

删除费用卡、执行模式、图片数量控件和当次积分上限设置，改为低摩擦但资金前置校验的单一路径：

### 创意任务

- 用户在自然语言中说“生成两张/三张”等数量，由 Brain 输出 strict `output_count`；前端不得解析或显示数量控件。
- Brain 输出 candidate 后，Compiler 校验 Skill、模型能力、张数和平台上限并生成 quote。
- Credit 核对余额并创建 reservation；成功后才进入读取、生成、检查和结果，进度中显示预计积分。
- 全程不显示费用卡。

### 电商任务

白底精修、商品主图、电商用途必须按顺序显示：

1. 结构化解析摘要：Skill、输入素材、平台/用途、比例、预计产物数、特殊要求。
2. 商品事实卡：商品身份、关键颜色、Logo/包装标识、可见文字、必需参考图，可编辑，未知字段不强迫填写。
3. 点击“确认商品信息”。
4. Brain 解析张数并进入 Compiler 报价、Credit 核对和 reservation。
5. 预留成功后进入生成进度。

不得增加费用卡、执行模式、数量控件、计划确认、独立报价页面、逐步骤确认或 Provider 二次确认。重复点击生成只能复用同一个 mock turn/quote/run。价格不可用、数量越界或余额不足时保留用户输入且不调用 Provider。

## 4. 修正批量、套图和画布执行

- B02 最后一步显示整个批量的总张数和预计积分；点击“开始批量创作”即提交，核对通过后进入 B03，不逐 SKU 确认。
- B09 先确认商品事实，最后显示覆盖全部图片类型和附加项的预计积分；点击“生成套图”即提交。普通规范警告可继续，高风险显示证据确认，内容安全硬拦截不可绕过。
- C02 点击“运行节点”时先校验输入并 compile，随后核对积分并运行，不弹确认框。
- C02 点击“运行工作流”时先检查环、悬空引用和 readiness，编译通过后核对积分并按拓扑运行，不增加确认步骤。

## 5. 补齐画布 Overlay

- 版本历史：点击节点版本角标打开右侧抽屉，按时间显示不可变版本。
- 版本对比：勾选两个版本，支持并排和拖动分割线比较；设为当前版本时创建新引用，不改写历史。
- 任务日志：顶栏入口打开右侧抽屉，可按运行中/失败/成功筛选，点击日志定位节点；结果未知不可自动重试。
- 导出：阶段 3b 显示，可选本次成功、当前选中或全部可下载产物；排除失败、隔离、删除和无权限项，使用异步进度和过期下载状态。
- 发布模板：列出保留的节点/边/公开参数和移除的私有素材/敏感信息，确认后发布不可变版本。

## 6. Overlay 清单

保留 21 个普通用户页面族（A01-A10、B01-B09、C01-C02）。独立管理台 O01-O12/O13 另行裁决；Overlay 只按以下 25 族实现，不再发明第四套清单。事实/风险确认是消息流内卡片；所有生成入口都不存在费用确认卡。

第一组 9 个：全局任务抽屉（通知态 S16 后激活）、移动导航抽屉、会话操作/删除确认、附件上传与资产选择、商品快速新建/编辑、产物大图预览、任务取消/重试/申诉动作、运营高风险操作确认、隔离产物复核详情。

第二组 7 个：批量导入映射/错误、部分失败重试、导出选项、分享创建/撤回/举报、模板解锁、参考图选择、平台规范证据与高风险确认。

第三组 9 个：添加节点菜单、上传/资产选择、节点全屏预览、版本历史、版本对比、删除影响确认、画布任务日志、导出/发布模板、revision 冲突处置。

## 7. 运营台与移动端

- 普通站不创建 `/admin` 或管理员入口；独立 `apps/admin` 使用受控 Host、独立 Session 和 O01-O12/O13 导航，普通 web host 请求管理路径返回 404。
- 移动端认证使用底部全高抽屉，关闭后保留 A04 草稿。
- 移动端筛选使用底部抽屉，返回详情时保留列表滚动位置。
- 移动 C02 只读：允许平移、缩放、节点预览、版本/任务查看和下载；隐藏拖线、参数编辑、运行与删除。
- 上传、生成和导出在切页后继续；返回时恢复快照，不重复提交。

## 8. 修改后自测

必须演示并确认：

1. 左侧可以看见“画布”，点击进入 C01，并能新建进入 C02。
2. 创意自然语言张数由 Brain 解析，积分核对成功后直接执行并显示预计积分。
3. 白底精修显示商品事实卡，确认后直接进入 Compiler/Credit，预留成功才生成。
4. 批量、套图、单节点和整链都以生成/运行按钮作为唯一提交动作，不再确认费用。
5. 任何页面都没有计划确认、费用确认框或用户金额上限；生成/运行按钮就是动作授权。
6. 报价过期、余额不足、重复点击不会创建重复任务。
7. 画布版本、任务日志、导出和 revision 冲突可操作。
8. 刷新后恢复登录、草稿、任务、画布节点和边。

完成后列出修改过的文件和以上 8 项自测结果，不要只回复视觉说明。
