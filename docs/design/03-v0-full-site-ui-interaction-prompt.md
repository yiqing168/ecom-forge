# v0 全站 UI 与交互实现提示词

> 将本文件完整内容直接提交给 https://v0.app/ 。目标是生成一个可运行、可点击、可演示完整用户流程的 Next.js 前端原型，而不是 UI 图片、营销首页或静态线框图。

---

## 任务

请为 **Ecom Forge** 构建一个面向中国电商卖家的 AI 图片创作平台前端原型。

这次交付必须包含：

- Next.js App Router + React + TypeScript。
- Tailwind CSS。
- shadcn/Radix 风格基础组件。
- `lucide-react` 图标。
- 画布页面使用 `@xyflow/react`，不要手写无限画布底层能力。
- `@xyflow/react` 是 React Flow 官方当前包名。请直接使用官方 `ReactFlow`、`NodeToolbar`、`Handle`、`MiniMap`、`Controls` 和 selection API，不要安装旧包 `reactflow` 或 `react-flow-renderer`，也不要另造画布引擎。
- 使用本地 mock 数据和前端状态完成可点击演示，不依赖真实 API、数据库、登录服务或图片生成 Provider。
- 所有按钮、菜单、弹层、抽屉、Tab、筛选和关键流程都必须可操作，不能只画静态页面。
- 页面语言为中文，Ecom Forge、Agent、Skill、SKU、Provider 等专名可保留英文。

不要生成：

- 营销 Landing Page。
- 后台仪表盘式首页。
- 画布优先首页。
- 大面积渐变、紫色主题、玻璃拟态、光球、霓虹和 3D 装饰。
- 虚构销售额、GMV、转化率和运营 KPI。
- 计划确认、逐步骤确认、费用确认卡、执行模式、图片数量控件或独立报价页面。A04 只在 Provider 调用前执行服务端积分核对。
- 思维链、tool JSON、Provider 原始错误和内部状态枚举。

## 产品主流程

```text
访问 /
  -> 进入 A04 访客态新会话
  -> 上传商品图或选择示例
  -> 输入创作指令
  -> 点击“开始创作”
  -> 未登录时打开登录弹层，保留草稿和附件
  -> 登录成功回到原输入
  -> 用户再次点击“开始创作”
  -> Brain 判断任务域并从自然语言解析图片张数
  -> 电商任务：显示结构化解析/商品事实卡；创意任务无需事实卡
  -> Compiler 报价，Credit 核对余额并创建 reservation
  -> 核对成功后显示生成进度，失败时就地提示且不调用 Provider
  -> 展示 Brain 所确定数量的生成结果
  -> 继续改图 / 下载 / 存资产 / 关联商品
```

默认体验保持低摩擦：**点击生成就进入 Brain/Compiler/积分核对**。不要显示费用卡、执行模式、图片数量控件、计划确认、独立报价页或逐步骤审批。电商任务只在对话内确认必要商品事实；积分核对和 reservation 成功后才进入图片 Provider。

## 视觉系统

### 普通产品壳

- 桌面基准：1440×900。
- 左侧固定 128px 紧凑导航栏；每个入口同时显示图标和 12px 中文文字，不能只显示图标。
- 顶部轻量工具栏高度 64px。
- 背景 `#F7F7F5`，主表面白色，主文字 `#171A1F`。
- 主动作色为靛蓝 `#2F49DF`，普通链接和正文仍使用墨黑，不把蓝色当正文颜色。
- 珊瑚色 `#E56A54` 用于异常，青绿 `#087B75` 用于信息/成功辅助，琥珀 `#B56A18` 只用于积分和费用。
- 最大圆角 8px。
- 使用细边框和克制阴影，不使用卡片堆叠制造层级。
- 中文字体优先使用 `Noto Sans SC`、`PingFang SC`、`Microsoft YaHei`。
- 页面标题 32-40px；分区标题 20-24px；正文以 16px 为基准且不低于 15px；操作标签至少 14px。12-13px 只允许用于非关键元数据并满足对比度。

### 左侧导航

本次是**全站原型**，默认将阶段 2、阶段 3 功能开关设为开启，因此桌面端左侧导航必须直接显示“画布”，不能只实现 1A 导航后把画布藏掉。

从上到下固定顺序：

1. 创作 `/`（1A）
2. 商品 `/products`（1A）
3. 资产 `/assets`（1A）
4. 作品 `/artifacts`（1A）
5. 任务 `/tasks`（1A）
6. 批量 `/batches`（阶段 2）
7. 套图 `/suites`（阶段 2）
8. 发现 `/discover`（阶段 2）
9. **画布 `/canvases`（阶段 3，使用 `Workflow` 图标）**

账户 `/account` 固定在左侧导航底部，不参与上方业务入口排序。

主导航“创作”始终回到 `/` 创作首页，不能进入 `/workspace/session/new`。会话栏“新对话”和商品、作品、参考图等带上下文的创作动作才进入 `/workspace/session/new`；用户从首页或空白会话提交后，创建并进入 `/workspace/session/:id`。

当前路由为 `/canvases` 或 `/canvases/:id` 时，“画布”导航项显示选中态。进入 `/canvases/:id` 后切换为 C02 全屏专业画布壳并收起普通主导航，但顶栏左上角必须提供“返回画布列表”。

正式按阶段发布时，可以通过 feature flag 隐藏未开放入口；隐藏阶段 3 时只是不显示“画布”导航项，不删除 C01/C02 页面实现。本次交给 v0 的全站演示不得隐藏。

1A 未登录用户只允许进入 A04 访客态；公开分享页随 S19 激活。点击受保护入口时打开登录弹层，不跳独立登录首页。

### 画布产品壳

- C02 使用独立全屏专业工作区。
- 进入 C02 后收起普通左侧导航。
- 顶部只保留：返回画布列表、画布名称、保存状态、撤销、重做、任务日志、积分、导出。
- 左侧只放画布工具。

## 全局交互

### 登录拦截

1. 未登录用户可以在 A04 输入文字、添加附件和选择示例。
2. 点击“开始创作”时打开登录弹层。
3. 背景仍显示 A04 原输入，使用半透明遮罩。
4. 关闭弹层后草稿和附件不丢失。
5. 输入任意合法邮箱和不少于 8 位的密码后，点击“登录并继续”。
6. 设置 `isAuthenticated=true`，关闭弹层，回到原输入。
7. 不自动发送；用户再次点击“开始创作”才生成。

### Mock 解析、确认与生图

登录后点击“开始创作”：

1. 把用户输入追加到消息流，并根据当前 Skill/mock 指令设置任务域：白底精修、主图、电商用途为 `ecommerce`；纯风格、创意海报为 `creative`。
2. Brain 从用户原话解析 `output_count`；“生成两张”得到 2，“生成三张”得到 3，未明确时使用 Skill 默认。前端不得用正则或本地关键词解析，也不显示数量控件。
3. `ecommerce` 先显示结构化解析和商品事实确认卡。用户可编辑商品身份、关键颜色、Logo/包装标识、可见文字和必需参考图；点击“确认商品信息”后直接进入 Compiler。
4. Compiler 校验张数、Skill、模型能力和平台单 turn 上限，生成 quote；Credit 核对余额并原子创建 reservation + workflow。
5. 生成进度依次为：`reading`“正在读取商品图” -> `pricing`“正在核对积分” -> `generating`“正在生成 2 张图片” -> `checking`“正在检查结果” -> `completed`，最终显示 2 张 mock 商品图。
6. 不显示费用卡、计划确认、思维链、内部执行步骤或逐 Provider 二次确认。
7. mock 价格不可用、余额不足或数量越界时不创建 Provider 任务，保留输入并提供“查看积分明细”或修改自然语言需求。

### 全局任务抽屉

- 顶部任务图标点击后，从右侧打开 360px 抽屉。
- 显示当前任务和最近任务。
- 点击任务进入 `/tasks/:id`。
- 切换路由不终止 mock 生成计时器。

# 页面规格

## A01 登录/注册弹层

### 触发

- 访客点击“开始创作”。
- 访客点击商品、资产、作品、任务、账户或画布入口。

### UI

- 宽 480px 居中弹层。
- 标题“登录后开始创作”。
- 说明“你的指令和附件会保留，登录完成后可继续发送”。
- 邮箱输入框。
- 密码输入框和显示/隐藏按钮。
- “忘记密码？”文字按钮。
- “登录并继续”主按钮。
- “注册账号”次按钮。
- “注册需邀请码或白名单邮箱”说明。
- 用户协议和隐私政策复选框。
- 右上角关闭按钮。

### 交互

- 邮箱格式错误：输入框下方行内提示，不改变弹层高度。
- 密码不足 6 位：显示行内提示。
- 未勾选协议：点击登录后提示。
- 登录成功：关闭弹层并回到触发前页面/草稿。
- 点击注册账号：弹层切换为注册态，不打开新营销页面。
- 点击忘记密码：切换为邮箱找回态。

## A02 注册与邀请

在 A01 弹层内切换，不单独占据应用首屏。

字段：邮箱、密码、邀请码。按钮“注册并发送验证码”。

交互：

- 邀请码为空时允许用白名单邮箱演示。
- 输入 `USED` 或 `INVALID` 统一显示“当前无法完成注册，请检查邀请码和邮箱是否正确”，不进入 A03，不创建 mock 邮件。
- 其他邀请码视为有效。
- 注册成功切换到 A03 邮箱验证态。

## A03 邮箱验证与找回

### 邮箱验证码态

- 邮件图标。
- 标题“验证你的邮箱”。
- 脱敏邮箱地址。
- “重新发送”按钮和 60 秒倒计时。
- 6 位验证码输入、60 秒重发倒计时和“返回登录”按钮；验证状态使用固定高度行内错误区，不出现“点击我已完成验证”的假完成动作。

显示部分脱敏邮箱、6 位数字验证码输入、10 分钟有效期和 60 秒重发倒计时。演示验证码使用组件测试/演示状态注入，不增加返回验证码的页面接口；输入正确验证码后设为已登录并回到 A04 原草稿，不自动发送。错误、过期、5 次耗尽、ticket 失效、限流和邮件暂不可用显示在固定高度行内状态区，不推动弹层内容。

### 找回密码态

- 输入邮箱。
- 点击“发送重置邮件”后进入成功提示。
- 提供返回登录按钮。

## A04 Agent 创作工作台

### A04-1 访客新会话

路由分工：`/` 是创作首页；`/workspace/session/new` 是会话区空白新对话；发送成功后进入 `/workspace/session/:id`。两种空态可以复用 Composer，但导航选中态、会话栏和返回闭环必须按路由区分。

UI：

- 顶栏左侧“新会话”与下拉箭头。
- 顶栏右侧“帮助”“登录”。
- 中央标题“今天想做点什么？”。
- 副标题“上传参考图，直接告诉我你想要的效果。”。
- 大型 Composer：
  - 多行输入。
  - 添加附件按钮。
  - 当前附件缩略图。
  - `@ 引用附件`。
  - “智能生图 Agent / 智能视频 Agent”。
  - “Skill”。
  - 智能生图 Agent 的比例/数量；智能视频 Agent 的 720P/1080P、比例、时长/数量。数量是“常用值 + 可编辑正整数”，不能锁死为少数候选；指令明确写“两张”“生成 6 张/条”时同步更新当前数量，并在解析/费用/结果中保持一致。
  - “开始创作”。
- 三个快捷入口：白底精修、人像焕新、照片意象重绘；入口由服务端 catalog 驱动，点击后必须更新同一套 primary Skill 选择状态。
- 四个“从示例开始创作”商品示例。

交互：

- 点击快捷入口：把对应指令模板填入输入框并聚焦。
- 点击示例图：把示例图加入当前附件并填入对应指令。
- 点击添加附件：打开附件选择抽屉。
- 支持拖拽本地图片到 Composer。
- 当前输入最多显示 10 个附件。
- 附件可预览、移除、拖动排序。
- 点击 `@` 或输入 `@`：只显示当前 Composer 中的附件，不能搜索全站资产。
- 首页 Composer 不显示固定“选择商品”控件。只有用户从商品、作品或明确的电商 Skill 进入时，才把商品/SKU 作为已绑定上下文显示为可关闭 chip；自然输入识别为电商任务时由对话事实卡承接商品信息。
- 在 `/` 提交成功：创建具体会话并进入 `/workspace/session/:id`；首页本身不显示“新对话”按钮或会话历史栏。
- 会话栏点击“新对话”：进入 `/workspace/session/new`；主导航点击“创作”：始终进入 `/`，并清空首页 Composer 临时态。
- 未登录点击开始创作：打开 A01。
- 已登录点击开始创作：进入 A04-2，并按任务域显示直接生成或商品事实确认状态；不得绕过 Compiler、积分核对和 reservation 创建 Provider 任务。

### A04-2 活跃会话

路由：`/workspace/session/:id`。

布局：

- 普通 128px 导航旁可以展开 280px 会话栏。
- 会话栏包含新会话、搜索、今天/昨天分组列表、重命名和删除。
- 中央为消息流。
- 右侧任务/产物抽屉默认关闭。
- 底部固定 Composer。

消息类型：

- 用户文本消息。
- 用户带附件消息。
- Agent 结构化解析卡。
- 商品事实确认卡，仅电商任务出现。
- Agent 简洁进度消息。
- 生成结果消息。
- 轻量错误消息。

不要显示费用卡、执行模式、图片数量控件、计划确认、独立报价页面、逐步骤确认、思维链或工具调用详情。Brain 解析张数后由 Compiler 和 Credit 完成服务端积分核对。

### A04-3 解析与确认态

电商任务在用户消息后依次显示：

1. 结构化解析摘要：Skill、输入素材、目标平台/用途、比例、预计产物数和特殊要求；允许修改解析错误。
2. 商品事实卡：商品身份、关键颜色、Logo/包装标识、可见文字、必需参考图；未知字段显示“未提供”，不强迫补齐无关字段。
3. 用户点击“确认商品信息”后，Brain 输出图片张数与工具参数并进入 Compiler；不显示总费用卡。
4. Compiler 产生预计积分后，消息流显示“预计消耗 N 积分”，Credit 同步核对余额并预留；重复生成请求只进入同一个 turn/quote/run，不重复冻结。

创意任务点击生成后走同一 Brain -> Compiler -> Credit 路径。价格、模型目录或数量变化导致校验失败时保留输入并要求重新生成，不产生费用卡或静默调整。

### A04-4 结果态

结果区显示四张候选图：

- 第一张默认选中并放大。
- 左右箭头或缩略图切换候选。
- 操作：继续改图、下载、存入资产、关联商品、更多。
- “继续改图”：将当前结果显式加入 Composer 附件，聚焦输入框，并显示 chip“正在修改：结果 1”。
- 继续生成新结果时保留旧结果，不覆盖。
- “下载”：模拟下载并显示 toast。
- “存入资产”：加入资产 mock 数据，显示成功 toast。
- “关联商品”：打开商品选择弹层。

### A04-5 失败态

- 在消息流显示“本次生成未完成”。
- 提供“重新生成”和“修改指令”两个操作。
- 点击重新生成重新运行 mock 进度。
- 不显示 Provider 原始错误。

## A07 资产库

路由：`/assets`。

UI：

## C02 无限画布编辑器

路由：`/canvases/:id`。

使用 `@xyflow/react`。

### 整体布局

- 全屏画布壳，隐藏普通 128px 导航。
- 顶栏：返回、画布名、保存状态、撤销、重做、任务日志、积分、导出。
- 左侧工具栏：选择、平移、文本节点、图片节点、视频节点、上传素材、资产库。
- 中央无限画布：节点、边、框选、拖拽、缩放、小地图。

### 节点类型

#### 文本节点

- 主体显示文本或结构化摘要。
- 输入可以来自文本或图片分析节点。
- 下方面板：prompt、文本模型、输出格式、运行。

#### 图片节点

- 主体显示当前图片、候选和版本角标。
- 输入可以是文本、图片附件。
- 下方面板：附件、角色、prompt、图片模型、比例、数量、运行。

#### 视频节点

- 主体显示封面、时长和播放按钮。
- 输入可以是文本、图片、视频。
- 下方面板：首尾帧、参考顺序、prompt、视频模型、比例、时长、运行。

### 节点选择效果

单击节点后必须同时出现：

1. 节点边框变为青绿色 2px，并显示选中光标状态。
2. 节点上方显示浮动操作条：
   - 预览
   - 复制
   - 删除
   - 更多
3. 节点下方显示就地输入面板：
   - 当前附件缩略图
   - prompt 输入框
   - `@` 当前附件引用
   - 模型
   - 比例/尺寸/时长
   - 数量
   - mock 预计积分
   - “运行节点”按钮
4. 面板通过 viewport portal 固定可读，缩放画布时不随节点缩小成不可用控件。

点击画布空白处取消选择并关闭上下浮层。

### 多选效果

- Shift+点击或框选多个节点。
- 不显示多个单节点面板。
- 只显示共享操作条：对齐、分布、复制、删除、分组。

### 连线与附件

- 从上游输出 handle 拖到下游输入 handle 创建边。
- 创建边后，上游输出自动出现在下游节点的附件栏。
- 附件栏显示来源节点缩略图、名称和角色。
- 删除附件等同删除对应输入边，但不删除上游节点。
- 删除上游节点前提示“将影响 N 个下游节点”。
- 手动点击“添加附件”时：
  1. 打开上传/资产选择器。
  2. 用户选择素材。
  3. 在目标节点左侧创建一个真实素材节点。
  4. 自动创建素材节点到目标节点的边。
  5. 不允许只生成隐藏附件关系。

### `@` 引用

- 节点 prompt 输入 `@` 时只显示该节点附件栏中的条目。
- 不搜索整个画布、会话历史或资产库。
- 候选显示缩略图、名称、角色和来源节点。
- 选择后插入不可变引用 chip。
- 对应边被删除后，chip 显示失效状态并阻止运行。

### 添加节点

- 点击左侧文本/图片/视频工具后，在画布中心创建节点。
- 右键画布空白处打开同样的添加菜单。
- 从现有节点输出 handle 拖到空白处时，打开“创建下游节点”菜单。
- 不允许 Agent 根据一句对话自动铺设整张画布。

### 运行节点

- 点击“运行节点”后验证必填附件和 prompt，再由 mock compiler 报价并核对 mock 余额。
- 若上游未完成，显示“等待上游完成”并定位附件。
- 节点面板可预先显示模型、数量和预计积分；“运行节点”是唯一主动作，重复点击复用同一个 quote/run。
- mock 状态：排队中 -> 生成中 -> 检查中 -> 成功。
- 成功后在节点内显示新候选和版本角标。
- 原版本仍可通过版本历史查看。

### 整链运行

- 顶栏按钮“运行工作流”。
- 点击后高亮将执行的节点和边。
- 通过环、悬空引用和上游 readiness 校验后，由 mock compiler 报价并直接开始 mock 执行。
- 不生成 Agent 计划确认页、费用确认框或逐节点确认。
- 按拓扑顺序更新节点状态。
- 非法环用红色边标出并阻止运行。

### 节点上方工具条细节

图片节点：预览、分析、去背景、指令编辑、下载、存资产、替换、更多。

视频节点：预览、下载、设首帧、设尾帧、替换、提取帧。

文本节点：编辑、复制文本、更多。

未开放能力不要显示灰色占位按钮。

### 版本历史与版本对比

- 点击图片/视频节点的版本角标或“更多 -> 版本历史”，从右侧打开 400px 抽屉。
- 历史按时间倒序显示缩略图、版本号、创建时间、来源任务和当前使用标记；点击版本只预览，不立即覆盖当前版本。
- 勾选两个版本后进入对比态，支持并排和拖动分割线两种查看方式。
- 点击“设为当前版本”时创建新的节点版本引用并更新当前画布 revision；历史版本保持不可变。
- 隔离、删除或无权限版本不显示原图，也不能设为当前版本。

### 画布任务日志

- 点击顶栏“任务日志”从右侧打开抽屉，按全部、运行中、失败、成功筛选。
- 每项显示自然中文状态、节点名、开始/结束时间、预计/实际积分和短 trace ID；点击后在画布中定位并选中对应节点。
- Provider 结果未知显示“本次生成未完成”，允许用户明确新建独立收费生成；原 attempt 不自动重投。明确失败同样显示重新运行入口。
- SSE 中断时抽屉顶部显示“正在重连”，先恢复任务快照再续订事件，不清空已有日志。

### 导出与发布

- 阶段 3b 开启后，顶栏显示“导出”和“发布模板”；3a 未开启 3b 时完全隐藏，不显示灰色占位。
- 点击“导出”打开独立 overlay，可选择本次成功产物、当前选中产物或全部可下载产物；默认排除失败、隔离、删除和无权限项。
- 确认后创建异步导出任务，在任务日志显示进度；完成后提供有有效期的下载入口，过期可重新创建导出。
- 部分导出失败时显示成功/失败清单，只重试失败导出项，不重新生成原产物。
- 点击“发布模板”列出将保留的节点/边/公开参数，以及将移除的私有素材、商品事实和敏感字段；用户确认后发布不可变模板版本。

### 画布保存与刷新

- 拖动节点、创建边、改 prompt 后显示“保存中”。
- 500ms debounce 后显示“已保存”。
- 数据写入 `localStorage`。
- 刷新后恢复节点、边、位置、参数和选中版本。
- 模拟 revision 冲突时打开弹层：重新加载或另存副本，不能静默覆盖。

## 正反向流程闭环检查

实现完成后必须逐条自测。任何一步只有视觉、没有状态变化或返回路径，都视为未完成。

### 正向主流程

1. `/` 直接进入 A04 访客创作页，不先进入营销首页、登录页或后台首页。
2. 访客添加图片和指令后触发登录弹层；登录完成返回原草稿，不自动发送。
3. 再次点击开始创作后按任务域分流：创意直接进入编译与积分核对；电商任务只确认必要商品事实，随后直接进入编译、积分核对、生成、检查和结果。
4. 结果能够继续改图、下载、存入资产、关联商品，并可从作品进入画布。
5. 画布中能够手动创建节点、连接节点、添加附件、使用当前附件 `@` 引用、运行节点和查看新版本。
6. 阶段 2 的批量、发现、套图能够从入口进入详情并回到对应列表；阶段 3 的画布能够从列表、作品和套图结果进入。

### 反向与异常流程

1. 登录弹层关闭、登录失败或返回时，原页面、草稿、附件和已选商品不丢失。
2. 从商品、资产、作品、任务、套图和画布详情返回时，保留原筛选、滚动位置和选中项。
3. 生成失败可重新生成或修改指令；重新生成不得覆盖历史成功结果。
4. 运行中任务取消、明确失败重新生成、Provider unknown 后用户明确新建生成，三种操作不能混用；unknown 原 attempt 永不自动重投。
5. 隔离作品和资产不能通过预览、下载、分享或选择器绕过访问限制。
6. 画布删除输入边后，对应附件立即消失，相关 `@` chip 失效并阻止运行；重新连接后恢复。
7. 删除上游节点必须先展示受影响的下游数量；取消删除后节点、边和附件保持不变。
8. 画布出现非法环时阻止整链运行，删除问题边后可恢复运行。
9. 刷新 A04、任务页或 C02 后，mock 登录态、会话、生成状态、节点、边、位置和参数能够恢复。
10. revision 冲突不得静默覆盖；“重新加载”放弃本地冲突改动，“另存副本”保留当前画布。
11. 所有抽屉和弹层都可用关闭按钮、遮罩或 Escape 正常退出；退出后焦点回到触发控件。
12. 浏览器前进/后退必须恢复对应路由页面，不产生重复发送、重复生成或重复创建节点。
13. 报价过期不得继续提交；刷新费用后保留输入、事实、批量条目、套图配置或画布选择。
14. 余额不足不得创建 reservation/run；返回修改参数后可重新估价，不能出现已失败任务或重复冻结。

### 产品边界复核

- A04 始终是第一入口；画布是阶段 3 的人工专业工作区，Agent 不自动规划或铺设画布。
- 所有生成入口都不显示费用卡、执行模式或当次积分上限；A04 还不显示图片数量控件，由 Brain 解析数量。Compiler 报价，Credit 在 Provider 前核对和预留；生成/运行按钮是唯一提交动作。所有场景都不显示计划确认或 Provider 二次确认，高风险后台操作、删除影响和冲突处理仍保留必要确认。
- A04 的 `@` 只引用当前 Composer 附件；C02 的 `@` 只引用当前节点附件，二者都不搜索全站或全画布。
- 普通应用壳和画布专业壳是两套明确布局，不同时显示普通侧栏与画布工具栏。
- 页面全部使用中国电商语境和中文文案，不生成通用 SaaS 仪表盘、营销数据或英文主界面。
