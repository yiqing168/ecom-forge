# 07 阶段 1A 用户流与 UI

### A04 多图独立状态（2026-10-13）

每个图片槽位只由自己的 task、attempt、retry 链与已发布产物驱动。整组的结果未知/复核提示不得把仍在运行的其它图片显示为失败，也不得隐藏其它失败图片的重生成入口。点击重生成只替换对应槽位；新任务详情尚未到达时不能继承旧任务的错误和 attempt。保留独立计费及未知结果提示，不自动重投。状态清单：成功+未知+运行混合、两张分别失败、单张重生成、retry 快照延迟/读取失败、刷新恢复及桌面/移动布局。

### A04 会话设计师锁定（2026-10-08，覆盖下方缓存/下一 turn 改选规则）

### A04 推理失败解释补充（2026-10-07）

### A04 设计师选择补充（2026-10-04）

## 1. 1A 体验目标

1A 只追求一个完整闭环：

```text
邮箱验证
  -> 获得内测积分
  -> 选择“商品白底精修”主 Skill
  -> 上传商品图
  -> Agent 解析需求
  -> 确认商品事实
  -> 确认预计积分
  -> 生成白底精修图
  -> 查看保真 warning/unknown
  -> 对本会话产物继续指令编辑
  -> 下载或存入资产库
  -> 查看积分流水
```

暂不承诺：

- 支付和公开充值。
- 视频模型、视频附件和视频生成。
- 完整套图流水线。
- 批量上传、批量确认和批量生成；1B 起补批量能力。
- 完整画布工作台。
- 官方参考图库和我的收藏；2A 模板/参考图库阶段补。
- 公开模板投稿。
- 公开分享、做同款、会员比较/购买和充值占位；对应阶段完成前完全隐藏入口。

## 3. Agent 工作台布局

1A 主入口是对话式 Agent，用于创意生图、电商从零建立商品档案并生成，以及本会话产物迭代。“从零”表示不要求已有商品档案；白底精修仍必须上传用户有权使用的商品原图并确认事实，不能从纯文本臆造真实商品。历史画布 Agent 只参考 Agent 架构、Skill 设计、Provider 调用、运行护栏和任务面板，不复用画布作为主交互。

用户主导航固定为“创作 / 生成 / 资产 / 作品”。“生成”进入 `/workspace/session/new`，桌面端同时展示服务端会话记录，移动端通过工作台顶部会话入口查看并继续历史生成；A09 任务中心保留深链接与后端能力，但在接入真实用户任务数据前不占主导航。

布局：

- 左侧：会话列表。
- 中间：对话流。
- 右侧：任务监控和产物面板。
- 底部：必选主 Skill、可选 Preset、推理/图片产品模型选择、输入框、附件、`@` 引用、`/` 技能入口；S16 激活后才扩展视频。

输入区能力：

- 文本输入。
- 上传图片，1A 最多 10 个附件。
- `@` 只引用当前输入区已绑定附件；资产库素材必须先通过“添加附件”显式加入当前 turn。
- `/` 打开与可见快捷入口相同的主 Skill 选择器；未选择主 Skill 时发送按钮禁用并提供“选择 Skill”入口。
- 模型选择器只消费 S14A active catalog：推理、图片各自可有多个产品化模型；显示能力/规格/积分，不显示 Provider、内部 model ID、Key、endpoint 或 CNY 成本。S16 前 video catalog 为空，不显示视频选择器。
- 快捷入口必须同时选择对应精确 primary，而不是只填指令模板；会话可保留上次选择供下一 turn 展示，但每次请求仍显式携带并由服务端重校验。主页输入区下方快捷入口与 Skill 下拉使用同一公开 catalog，名称、顺序和完整可选集合一致，不截取前几个或维护本地名单；窄屏自然换行。2026-10-08 起“实景拼贴·写意纸境”暂停公开新入口，由现有 manifest 的 `catalog_enabled=false` 控制，保留内容与评测，不新增执行层特例。
- 风格 1/2/3 等同一任务变体作为当前 primary 的 Preset；Preset slot 必选时未选也禁用发送，可选 slot 不由 Agent 静默补默认。
- 推理模型选择保持在紧凑高级设置中；图片模型与当前生成规格一起展示，均只来自 S14A active catalog。首次进入可展示 catalog 的显式默认项，但每次 turn 仍固定用户可见选择并由服务端重校验，不能在执行中静默替换。S16 前不展示视频选择器。
- 输入区模型选择按会话隔离；历史会话不得继承其他会话或新会话的浏览器选择。进入历史会话时，优先恢复该会话的本地选择草稿，否则恢复最近一轮的产品模型快照；没有模型快照的旧会话才可展示 catalog 默认项。历史 entry/version 不再可用时要求用户显式重选，不静默换成默认模型。会话与 catalog 尚未加载完成时禁止提交；刷新快照、分页或实时更新不得覆盖用户当前的模型选择。新会话选择与历史会话缓存分开，切换只影响后续新建 turn，不修改历史 turn 或正在执行的模型绑定。
- 意图分类不单独计费，只作为路由和体验判断。

## 4. 邀请内测流

```text
访问站点
  -> 进入 A04 访客态新会话
  -> 输入创作指令
  -> 点击发送，若未登录则打开 A01 登录/注册弹层
  -> 输入邀请码或使用白名单邮箱
  -> 服务端先校验内测资格；无效资格停留在注册态且不发邮件
  -> 创建有时限的待注册申请并发送 6 位邮箱验证码（不创建账号）
  -> 在同一弹层输入验证码
  -> 验证码通过后原子创建正式账号、核销邀请码并发放内测积分
  -> 回到 A04，恢复原输入内容，由用户再次确认发送
```

规则：

- 验证码通过前不存在正式账号，也不能登录或生成；注册完成后邮箱已验证，不再有后置验证解锁步骤。
- 邮箱验证码有效期 10 分钟，重发按钮显示 60 秒冷却；重发成功后旧验证码立即失效。
- 验证码输入支持粘贴、自动前进、退格回退和键盘操作；错误、过期、尝试次数耗尽、限流和邮件暂不可用均使用不引起弹层跳动的行内状态。
- 无效、过期、用尽、停用或邮箱不匹配的邀请码统一显示“当前无法完成注册，请检查邀请码和邮箱是否正确”，不暴露具体内部原因，也不进入验证码步骤。
- 找回密码申请始终进入统一验证码状态；页面使用“如果该邮箱已注册并完成验证，验证码将发送至该邮箱”，不得向未注册或未验证邮箱宣称邮件已经发送。
- 注册、验证和找回均保持在 A01 弹层状态机中，不新增独立营销页；关闭后保留 A04 草稿和附件。
- 验证成功后不自动发送访客草稿，仍由用户再次点击发送。
- 注册赠送和邀请码奖励必须受设备/IP/活动总量/风险状态约束。
- 内测积分为测试额度，不承诺现金价值、转让、提现或长期有效。
- 风险账户可被冻结，冻结后仅允许查看历史和申诉。

> 当前入口状态（2026-08-30）：商品导航和“商品白底精修”主 Skill 暂时隐藏于用户界面，后端路由、Skill 内容与历史会话能力保留；恢复入口前需重新进行产品验收。

> 会员权益页面暂未接入真实 `/api/membership` 查询，用户侧不开放 `/account/membership`，不得展示静态会员等级、积分、日期或权益。

## 5. 商品白底精修主流程

1. 用户上传商品图。
2. 用户已选择“商品白底精修”主 Skill；Agent 在该 Skill 边界内理解电商需求。若指令明显不匹配，只提示切换，不自动替换。
3. 关联或创建商品档案：
   - 商品名称。
   - SKU/货号，可选。
   - 主商品图。
4. 展示结构化解析卡：
   - 技能：商品白底精修图。
   - 输入素材。
   - 目标：白底、去背景、基础精修。
   - 预计产物数。
5. 展示商品事实确认卡：
   - 商品身份。
   - 主色/关键颜色。
   - 主 Logo 或包装标识。
   - 可见文字。
   - 必需参考图。
   - 商品身份和可见文字处置结果是白底精修的阻断最小集；“当前无可见文字”需要用户显式确认，无法辨认可保持未知并按任务需要澄清。
   - 颜色、Logo/包装标识在可观察时展示确认；材质、结构、尺寸等只在当前任务需要时出现，未知字段不为填满表单强行追问。
6. 用户确认商品事实后，Brain 输出图片张数与工具参数；Compiler 生成 quote，Credit 在图片 Provider 调用前核对余额并原子预留。界面不显示费用卡或当次积分上限。
7. 积分核对和预留成功后进入任务队列；失败时保留输入与事实，只显示余额不足、价格不可用、数量越界或并发限制等就地提示。
8. 右侧任务面板展示：
   - 排队中。
   - 生成中。
   - 保真检查中。
   - 完成/失败。
9. 产物面板展示结果和风险提示。

## 6. 创意生图流程

1A 固定包含 10 个创意 primary Skill：自由创作、人像焕新、照片意象重绘、实景拼贴、实景拼贴·写意纸境、极简拼贴、实景转译·日常记忆页、叙事电影海报、日常反差海报和虚空线稿。本会话连续改图是共享 Tool/lineage 能力，不作为 primary Skill。自由创作承接纯文本或可选参考图的通用从零生图；其余 9 个专门 primary 固定各自的素材职责，不能被自由创作或 Agent 在运行中替换。

```text
用户选择具体创意 primary，可选其 Preset
  -> 输入创意需求或上传参考图
  -> Agent 在所选 Skill 的素材职责和知识边界内理解
  -> Brain 从“生成两张/三张”等自然语言解析图片张数，未明确时使用 Skill 默认
  -> Compiler 校验张数、模型能力和平台单 turn 上限并生成 quote
  -> Credit 核对余额并创建 reservation
  -> 生成产物
  -> 下载、存库或继续本会话迭代
```

图片数量不是前端控件，也不由前端正则或关键词解析。Brain 必须把最终数量作为 strict candidate 参数交给 Compiler；余额不足、价格未知、数量越界或 reservation 失败时不得调用图片 Provider。

自由创作由用户填写文字指令或完整提示词，不显示或要求选择风格 Preset，设计师选择沿用通用方法层。没有附件和风格选择也可发送有效文字请求；开始后只加载自由创作自身的通用说明，共享知识按需加载，不自动套用其他主 Skill。完整提示词的明确决定优先，不为体现设计师而强制改写构图或制造多图差异。

创意任务不强制商品事实确认，不进入商品保真校验；如引用商品图并要求电商用途，Agent 应提示用户切换到对应电商 primary，不能自行切换或继续按错误 Skill 执行。

商品白底精修在 1A 同时支持服饰鞋包、美妆个护、食品饮料、家居生活、宠物用品、运动户外和数码配件 7 个热门类目 auxiliary。类目由已确认商品事实和当前 primary 的精确一跳 allowlist 驱动，用户不在前端单独选择 auxiliary；事实不足时追问或保持 unknown，不能由模型猜类目后补造材质、参数、功效或兼容性。

## 7. 积分核对 UI

| 场景          | UI                                                                  |
| ------------- | ------------------------------------------------------------------- |
| 创意生成      | 点击生成后直接进入 Brain/Compiler；编译完成后在进度中显示预计积分   |
| 电商任务      | 结构化解析可编辑、商品事实确认；确认事实后直接进入积分核对          |
| 余额不足      | 保留输入，显示所需积分和余额不足动作；不调用 Provider               |
| 价格/目录漂移 | 保留输入并要求刷新后重新生成；不静默换价或换模                      |
| 数量/能力越界 | 提示调整自然语言需求或模型；不静默减少张数                          |
| 重试          | 新建幂等生成动作并重新报价；accepted/outcome_unknown 不提供普通重试 |

1A 不存在费用卡、执行模式开关、数量控件或用户设置的当次积分上限。模型选择器可展示公开计价单位；Compiler 完成后展示本次预计积分，结果与积分流水展示实际结算。Provider 结果未知时展示“本次生成未完成”，停止生成动画，允许用户明确发起一笔新的独立收费生成；原 attempt 不得自动重投，未结算冻结最迟 30 分钟自动退回。

## 8. 风险提示 UI

1A 保真只输出 `warning/unknown`：

| 状态      | 展示                                 |
| --------- | ------------------------------------ |
| `pass`    | 可弱提示或不提示                     |
| `warning` | 黄色提示：结果可能与确认事实存在风险 |
| `unknown` | 灰色提示：证据不足，需人工核实       |
| `blocked` | 1A 不启用；2B 后用于确定事实冲突     |

高风险确认 2B 校准后启用，1A 不出现确认卡：

- 展示用户确认前看到的证据。
- 明确“AI 无法可靠判断，请人工核实”。
- 用户确认后才能导出为上架素材。
- 记录 `risk_confirmations`。

内容安全拦截：

- 与保真提示分开展示。
- 不给出可绕过审核的提示词建议。

1A 简化上架前检查清单：

- 展示“建议人工复核”提示，不伪装为平台规范通过。
- 提示用户检查尺寸、背景纯净度、文字清晰度、主体完整性和商品事实一致性。
- OCR 文字清晰度、主体占比和平台规范自动判定后置到 2B/3+。

## 9. 本会话改图流

允许：

- 用户对本会话生成产物输入“去掉吊牌”“背景调暖”“换成浅灰底”等指令。
- 费用走指令编辑档。

禁止：

- 对话直接修改套图产物。

被禁止时展示：

```text
这张图不属于当前会话，不能在这里直接修改。画布能力尚未开放，请先下载或回到原生产入口；S24 激活后这里才显示可操作的画布跳转卡。
```

S24 激活前只提供返回原生产入口的普通文本，不显示画布跳转卡片；S24 激活后才显示带上下文的画布跳转卡片。

新用户完成邮箱验证后，用赠送积分通过对话完成：
