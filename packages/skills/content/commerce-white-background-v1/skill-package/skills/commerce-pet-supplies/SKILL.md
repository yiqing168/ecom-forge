# 宠物用品类目知识

只补充宠物用品的买家决策、结构与适配证据、声明风险和白底精修边界，不用宠物表情替代产品事实。

## 买家问题

- 商品轮廓、开口、扣具、牵引连接、通风孔、调节和可拆部件是否清楚？
- 商品尺度、填充厚度、材质与宠物接触关系是否保持原样？
- 套装数量、口味、规格、清洁方式和适用范围是否有资料支持？
- 素材中有宠物时，其身份、姿态、肢体和接触遮挡是否稳定？
- 毛发、网布、透明罩和细带等复杂边缘是否完整？

## 可信证据

- 以扣具、织带、缝线、连接点、通风孔、调节件、填充和开合证明商品结构。
- 以来源素材中的宠物身体比例、受力、接触位置、遮挡和自然动作证明已有使用关系。
- 以商品纹理、网布透明度、边缘和可见清洁结构证明材质与维护方式。
- 尺寸、体型范围、口味、材质、承重、使用与清洁信息只采用已确认事实。

## 声明风险

不得推断适用品种、年龄、体重、承重、医疗、治疗、驱虫、营养、安全认证或行为改善效果。宠物的开心、安静和亲近不能证明功效；不得凭空新增宠物、食物、玩具或使用动作。

## 类目特有失败

- 毛发、网布、牵引绳和透明部件被抠断、封死或互相穿插。
- 扣具、连接点、调节件、通风孔和安全部件被增删或移位。
- 修图改变宠物身份、姿态、肢体数量或与商品的接触关系。
- 用宠物吸引力掩盖商品结构，或暗示未经证实的适配和行为效果。

## 白底精修输出口径

固定商品结构、调节状态、套装、材质和原有宠物关系，只处理边缘、背景、曝光和自然接触阴影。分别精修毛发、织带、网布和透明件，检查穿插与肢体异常。原素材没有宠物时不新增；适配事实不足时不推断。
