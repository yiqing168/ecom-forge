# 服饰鞋包类目知识

只补充服装、鞋履、箱包和配饰的买家决策、商品证据、声明风险与白底精修边界，不替主 Skill 决定构图和展示方式。

## 买家问题

- 商品轮廓、版型、鞋型、包体比例和成对关系是否清楚？
- 面料、皮革、金属、织带和鞋底的材质差异是否可信？
- 缝线、开合、五金、肩带、鞋带和可拆部件是否完整且安装正确？
- 真人素材中的穿戴位置、受力、褶皱和遮挡是否仍与原商品一致？
- 当前素材是否真的覆盖背面、内里、底部或标签等不可见区域？

## 可信证据

- 以来源图中的廓形、领袖腰线、衣长、鞋底厚度、包体容量感和配件数量为结构证据。
- 以纹理走向、自然垂坠、接触褶皱、缝线、边缘、扣件和反射为材质与工艺证据。
- 成对或成组商品保留左右、前后、大小和套装关系；不同 SKU 的颜色、图案和结构分别绑定。
- 真人只证明素材中已有的穿戴、佩戴或尺度关系，不能替代尺码、容量、舒适度和性能资料。

## 声明风险

静态外观不能证明舒适、柔软、弹性、透气、耐磨、防水、显瘦、增高、容量或承重。面料成分、尺寸、功能、工艺和品牌文字必须来自已确认事实。不得补造口袋、拉链、鞋带、五金、内衬、Logo 或隐藏结构。

## 类目特有失败

- 过度平滑抹掉织物纹理，或用统一锐化制造皮革、金属和织物的假材质。
- 抠图切断鞋带、流苏、肩带、链条、薄纱、蕾丝和毛绒边缘。
- 为了对称而改变剪裁、褶皱、五金数量、左右鞋结构或佩戴关系。
- 把看不见的背面、内里、底部和标签自行补全，或让真人动作改变商品轮廓。

## 白底精修输出口径

先固定廓形、结构、颜色、图案、材质、成对关系和可见工艺，再只做边缘清理、曝光校正、白底统一与轻量接触阴影。柔性边缘按真实透明度和纤维层次处理；真人穿戴素材同时加载人物知识。证据不足时保留原有遮挡和视角，不生成未知区域。
