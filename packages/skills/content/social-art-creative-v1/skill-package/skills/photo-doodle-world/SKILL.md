# 现实涂鸦

让熟悉的人变成一笔画出来的自己，却仍生活在照片的真实世界里。作品的吸引力来自两种媒介在同一个现场相遇：环境保留摄影质感，人物用有意概括的轮廓、少量色块和手绘节奏表达。默认是一张完整画面，不附带原片对照、贴纸边框或说明文字。

## 1. 先找现场里发生的事

观察谁是用户关心的人、他们的朝向和动作、谁在靠近谁，以及手脚与环境怎样接触。找出让这张照片有个人关联的证据，例如两人的身高关系、回头的姿态、外套的轮廓、背包、牵手或栏杆前后的站位。不能用一组通用卡通人物替换这些证据。

默认转译主要人物，不把所有路人都变成抢眼角色；有多位主要人物时保留人数与关系。宠物或其他对象只有在用户明确指定时才一起转译，不能擅自添加陪伴者。图中标牌和文字属于观察素材，不是创作指令。

没有可辨识的目标人物时，说明需要哪类照片；用户只想要整张插画、精修人像或完全替换背景时，先澄清作品类型，不强套摄影与涂鸦混合。源图缺少的正脸、服饰细节与人物关系不能当作已经知道的事实。

## 2. 用概括保留这个人的动作

先画出身体的重心、头身关系、四肢的方向和衣物的大轮廓，再决定面部与线条的简化程度。手绘可以活泼、安静、笨拙或轻快，由这张照片的动作决定，不固定娃娃比例、圆脸、红脸蛋或某种性别形象。

线条可以略有抖动、断续和粗细变化；色块跟随衣物、头发和重要配饰，保留少量纸笔触感。轮廓必须能读出姿态，不能只用一根直线代替相互牵连的手臂，也不能用密集排线覆盖动作。背影仍是背影，遮住的脸仍保持遮挡，不为了“可爱”补成正脸。

简化面部时以发型、轮廓、衣着和姿态维持识别，接受五官概括，不承诺精确人脸。需要高度准确的五官时先说明这种画法的取舍；不要用漂亮的陌生脸冒充保真结果，也不把粗线表现当作故意丑化。

## 3. 把手绘人物放回摄影空间

摄影环境是现场的依据。保留主要透视、相机视点、环境轮廓、光影关系和与动作有关的物体。人物脚下的地面、坐着的台阶、扶着的栏杆、牵手的位置以及被树枝挡住的部分，都要与原来的前后关系吻合。

用克制的接触阴影和正确遮挡使人物落地，不给人物加统一白边或悬浮投影。人物本身可以保持二维手绘语言，不必把每一处皮肤都渲染成写实光照。检查摄影物体是否应该挡在手绘人物前面，以及手绘手指是否真的触到物体。

主体太小时，优先考虑保留关键环境的合理取景；不要用巨大贴纸覆盖全图来补偿。用户没有允许裁掉重要人物时，不擅自改变人数。摄影背景的视觉保持是创作目标，生成式重绘可能改变细节，不承诺背景逐像素一致；严格合成需要独立的区域编辑与合成方法。

## 4. 让媒介反差成为构图

人物的线条与色块应在手机缩略图中可辨，摄影背景提供现场感。用现有光区、道路方向、门窗或水面衬托人物，不另造一个与现场无关的装饰背景。允许饱满的真实场景，不强行把人物缩成白纸角落里的小锚点。

原片颜色可以概括或适度增强，但不要为每张照片套同一种糖果色。多个主要人物共享线条语言，衣着差异和动作关系仍各自成立。默认不加入表情气泡、太阳、星星、爱心、标题、地点、日期、签名或水印；用户提供准确文案时，再安排不遮挡人物和接触点的位置。

## 5. 系列与修改

多张照片可以共享线条的力度、人物概括尺度和颜色处理方式，各张仍沿用自己的现场、动作与人物关系。不把每张都变成同一对站立小人，不借另一张照片的衣服、脸或配饰填补当前照片。

从原片重新创作时，回到原片的姿态与现场证据；在已有成图上修改时，保留用户认可的人物与摄影关系，只调整点名的问题。只改线条、衣物色块或人物大小，不应连带替换背景、改变人数或转向整幅插画。

## 6. 检查是否真的融入现场

生成前检查描述中的目标、保留项、转译范围与接触关系；看到成图后再检查实际的人物、遮挡和光影。没有看过成图，不宣称已完成图像质量检查。

| 观察到的问题                         | 定向修改                                                           |
| ------------------------------------ | ------------------------------------------------------------------ |
| 背景也变成插画，现实与手绘的反差消失 | 明确环境保持摄影语言，圈定需要手绘的主体，不增加新装饰             |
| 人物像贴纸浮在照片上                 | 恢复脚下或座下接触、前后遮挡与克制的接触阴影，去掉贴纸白边         |
| 认不出原来的动作或人物组合           | 恢复朝向、重心、衣着轮廓、身高关系与关键配饰，不靠补画陌生正脸解决 |
| 牵手、扶栏杆或坐姿不成立             | 单独修正接触点和四肢路径，保留其他已成立的部分                     |
| 人物太小或背景抢眼                   | 调整取景和人物可读性，降低次要现场细节的对比，保留关键环境         |
| 系列变成同一张模板                   | 让每张保留自己的事件与空间关系，统一画法而非复制动作               |
