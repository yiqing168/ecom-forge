# 绒线微景

把熟悉的生活整个变成柔软、可触摸的微型世界。吸引力先来自生活事件、空间和体积，再来自针脚与纤维；不是给原照片加一层毛线纹理，也不是放一只钩织娃娃在摄影背景前。

## 1. 找到值得变软的生活关系

从照片找一个真实锚点与其周围关系：自家窗边与蜷着的猫、熟悉街口的转角与步行路线、桥和水面的上下关系，或两人相邻的姿态。确定哪些轮廓、颜色和前后位置让它仍是这个场景，再删减不影响识别的细碎物件。

“微景”指材料尺度与观看感，不要求把全场景缩到白底角落。普通街角、室内、乡间和没有著名地标的地方都能成立，不用自动补旅游建筑、国旗、招牌或纪念物。没有源照片时先补素材；源图模糊到无法判断关键动作或空间时，说明缺失证据，不靠常见旅游模板填空。

人物和动物保留数量、朝向、轮廓、衣着或毛色线索及互动，面部与毛发可以做艺术概括。不为所有人生成同一张玩偶脸，不把幼儿变成成人，也不以“可爱”覆盖用户不想改变的关系。精确五官或逐像素复原不属于这种材料转译的承诺。

## 2. 先搭连续场景，再铺纤维

以大形体、前后遮挡和明暗建立整体空间，再安排针脚。道路要连通，水域和岸线要分开，墙、窗、桥、台面与人物有明确的尺度关系。形体是连续软体积，不是一叠薄纸片，也不是没有支撑的悬浮碎块。

选择能读出源图事件的视点，保留必要的透视方向；近景可以亲近，中景可以展现一段生活路径。不要一律改成正上方玩具沙盘、环形小岛或塞满地标的城市集合。景物繁多时，以少量主要体积组织层次，而不是把每一处细节都做成毛球。

主要人物、宠物与生活物件的接触必须成立：坐垫略有压缩，足部与路面接触，手臂能绕过身体，靠在一起的角色有合理的叠压。柔软不意味着任意融化，桥、楼梯和家具仍保留足够结构来识别用途。

## 3. 不同物体共享一种纤维世界

确定一种主导的纤维尺度和制作语言，再让不同表面顺着形体变化，不把所有东西都覆盖同样的平铺针脚。

| 场景部分             | 让材料参与造型的方法                                                     |
| -------------------- | ------------------------------------------------------------------------ |
| 人物、动物和柔软物件 | 用圆润但可读的体积、少量针脚方向和边缘绒毛保留轮廓，接触处稍压缩         |
| 建筑、家具与路面     | 以较紧实的编织面和缝合边维持结构，细节由门窗、折角或分块体现             |
| 水面与岸线           | 用连续、有方向的纤维带和色面表达水的流向，保留与岸的边界，不画成真实液体 |
| 植物与地形           | 以成簇的柔软体积、纤维生长方向和层级体现，不逐根编出全部枝叶             |
| 天空与远景           | 以简洁的织物面或退远的软体积统一环境，清晰度和对比逐渐降低               |

全场景进入统一材料语言，包括道路、水和天空，不能只有人物与树是毛线，其余仍是普通照片。纤维需要可见但不过长，不用密集浮毛遮掉眼睛、手脚、窗洞或路径；避免软糖、塑料、毛毡平贴与硬纸层混杂到无法辨认工法。

## 4. 体积、光色与手机可读性

用统一的主要光向、柔和但清楚的明暗与接触阴影建立体积。景深可以提示微型尺度，但焦点应覆盖主要动作和足够的环境关系，不用强烈移轴模糊抹掉场景。微小针脚在缩图中会消失，轮廓与大色面必须先成立。

从源图的识别色与光温发展色彩，适度重新组织，允许明亮、克制或有冷暖对比，不固定粉彩、彩虹和暖黄色。将最强对比放在事件附近，次要环境承托它，不能每一个纤维结都抢主角。

默认一张完整作品，无额外文字、标签、地点、日期、签名与水印。源图里的标牌首先是形体证据；用户明确要求文字且提供准确文案时，再安排能读清的承载面，不让乱码冒充地点真实性。

## 5. 多图统一与局部修改

同一组沿用主要纤维尺度、针脚语言、光向和综合色，各张保留自己的路径、动作与识别锚点。不共享一个固定沙盘布局，不复制其他照片的地标、人物或宠物。

从原片重新生成时保留原片证据；基于认可成图修改时，只调整点名的问题，例如缩短绒毛、加强道路边界、降低背景针脚密度或恢复衣物颜色。不能因改一项材质参数就换掉人物关系、建筑结构或场景故事。

## 6. 检查世界是否连续而可读

生成前检查场景、材质和接触描述；看到结果后再判断针脚、体积和身份是否实际成立。未查看成图，不把文字自检说成自动验图。

| 观察到的问题                       | 定向修改                                                     |
| ---------------------------------- | ------------------------------------------------------------ |
| 只是摄影背景前放了毛线人物         | 将道路、建筑、水和远景也转成统一纤维形体，保留原场景布局     |
| 场景糊成一团绒毛                   | 减少浮毛和局部纹理，恢复大体积、路径边界和明暗层级           |
| 只有放大才看出材料，缩图像普通照片 | 加强软轮廓、关键缝合边、受力压缩与可读的大针脚，保持主体清楚 |
| 所有人都是同一个娃娃               | 恢复不同轮廓、发型、衣物、朝向与身高关系，避免新增五官承诺   |
| 街道断开、水域和墙混在一起         | 修正连通与分界，使材质方向跟随实际形体                       |
| 看起来与纸雕只是换纹理             | 建立连续软体积、弯曲与接触压缩，去掉硬切纸边和离散纸层       |
