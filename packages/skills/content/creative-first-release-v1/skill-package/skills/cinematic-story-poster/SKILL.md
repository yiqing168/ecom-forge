# 叙事电影海报

设计一张海报，不是给剧照压上片名。先判断这部影片要观众**感到什么正在发生**，再把它压缩为一个让人停下来的视觉证据。

一张作品只由五件事成立：**一个影片冲突、一个视觉母题、一个构图动作、一个标题策略、一个已证实的信息层级。** 标题可以是主视觉，但它必须进入电影的空间；人物、场景、物件、颜色与文字都要证明同一个冲突。

## 2. 输入解析：先找影片的心脏

用户可能只给出片名、梗概、一个角色关系或一张授权剧照。信息不足时，在现有资料上做最小合理假设；不要擅自把它发展成完整剧情、真实排期或营销事实。

在内部建立 Film Card，不向用户展示。

| 项目         | 必须确定的内容                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| 类型承诺     | 观众应该先读到何种体验：亲密、冒险、喜剧、恐惧、压迫、失落、奇想、成长、悬念或辽阔。不要只写“电影感”。 |
| 核心冲突     | 以可见关系写成一句话：谁/什么与谁/什么之间正在发生怎样的不可兼得。                                     |
| 人物关系     | 单人、两人对峙、群像、人与空间、人与物件、人与不可见力量，六选一。                                     |
| 视觉母题候选 | 从故事中找至多三个可见证据：门、桌、窗口、距离、路、伤痕、倒影、容器、光源、重复物、边界或缺口。       |
| 一级母题     | 只选一个，必须在小缩略图中先于全部细节被读到。                                                         |
| 标题事实     | 用户是否提供准确片名、语言、字数、已有标识或必须显示的事实信息？没有就默认无字或工作片名。             |
| 观众与媒介   | 是竖屏社媒预告、院线式主海报、影展提案还是概念封面？这决定画幅与信息量。                               |

将 Film Card 压缩成一条视觉命题：

`用 [一级母题] 让 [主体/关系] 在 [构图动作] 中显出 [冲突的可见后果]；[标题] 作为 [证词/门/伤口/光/秩序/阻力] 参与其中。`

例如：`用一张空椅对着被切开的长桌，让两位未现身的人显出制度性的对峙；片名像会议记录中被擦除的一行。` “高级、史诗、悬疑、好莱坞感”不是视觉命题。

## 3. 画幅与信息密度

默认使用 **9:16 竖幅**，适合手机端预告、概念发布与短片传播。用户明确要求时可选择 2:3 影院式竖幅、4:5 社媒竖幅或横版；单次只使用一种画幅，不做同画面多比例拼接。

| 海报类型         | 主视觉占比 | 标题占比 |     文字总量 | 适用条件                                     |
| ---------------- | ---------: | -------: | -----------: | -------------------------------------------- |
| **Key visual**   |     45–75% |    0–16% | 0–2 个文本块 | 影片信息不全、强调氛围或希望后续做精确排字。 |
| **叙事主海报**   |     40–65% |   12–28% | 1–3 个文本块 | 已有准确片名，主体关系与标题都必须可读。     |
| **文字结构海报** |     25–55% |   25–45% | 1–2 个文本块 | 片名短、文字本身能成为空间/物件/遮挡关系。   |

文字总量包括片名、宣传语、姓名、日期和版权行。不得为了“像电影海报”自动填满底部小字；若用户没给明确事实，宁可保留安静空间。

## 4. 选择一个构图动作

每张海报只选一个主构图动作。它决定底图的深度、主体尺度、承载面和标题位置；最多保留两个从属证据。

| 构图动作       | 画面关系                                               | 适合的叙事                           | 不要这样用                                             |
| -------------- | ------------------------------------------------------ | ------------------------------------ | ------------------------------------------------------ |
| **临场目击**   | 镜头贴近一个瞬间、眼神、手势或即将发生的动作。         | 肉身压力、爱情、运动、惊悚、成长。   | 不要加第二个抢焦点的脸或不相关动作。                   |
| **距离与门槛** | 人/物与门、窗、路、岸、走廊、屏幕或边缘拉开距离。      | 分离、旅程、离开、等待、孤独、未知。 | 不要把空场做成无意义的雾或脏黑。                       |
| **空间对峙**   | 长桌、阶梯、座位、墙面、走廊、舞台或透视线把关系拉开。 | 制度、家庭、法政、群像、秘密、权力。 | 不要只摆人头；空间必须讲冲突。                         |
| **物证隐喻**   | 单一物件、痕迹或局部材料承受缺席者/事件的重量。        | 悬疑、文艺、纪念、心理、灾变、奇想。 | 物件须来自故事，不要自动用锁、玫瑰、眼睛、面具或时钟。 |
| **身体与世界** | 人物尺度被巨大的地形、城市、机械、天空或群体改变。     | 史诗、科幻、战争、生存、冒险、运动。 | 不要默认人物远征队、末日云层、金色天光或游戏概念图。   |
| **标题介入**   | 片名字形切开、遮挡、承接或延伸视觉母题。               | 标题本身是故事动作的一部分。         | 没有合格字体/承载面时，不强行做巨型文字。              |

“群像”“书法”“拼贴”“监控感”是材料或形式选择，不是构图动作。它们只能在影片冲突需要时作为从属语言出现。

## 5. 建造底图与标题的共同空间

先定义背景承担的角色，后定义文字位置。底图不是填充，标题也不能像悬浮水印。

| 背景承载面                   | 标题可做的动作                     | 视觉后果                             |
| ---------------------------- | ---------------------------------- | ------------------------------------ |
| 天空、雾、墙面、雪地、布幕   | 悬置、压低、透出、被光吞没。       | 留出呼吸、未知或宏大尺度。           |
| 桌面、地面、道路、书页、屏幕 | 平躺、拉远、随透视收缩、像记录。   | 建立秩序、证词、时间或行进。         |
| 玻璃、水面、金属、镜面、雨痕 | 反射、断裂、被遮挡、像第二层画面。 | 制造分离、记忆、窥视或不确定。       |
| 门框、窗、走廊、衣物、边界光 | 被切断、跨过、卡在缝隙、形成阻力。 | 把标题转化为门槛、伤口或关系。       |
| 暗部、影子、背面、空座位     | 隐现、擦除、低声出现。             | 让文字成为缺席、秘密或未说出口的话。 |

明确标题区的坐标与面积：顶部、中央、下三分之一或沿透视轴；不要简单写“居中大标题”。标题必须避开主体的眼睛、关键动作和唯一物证，除非遮挡本身就是命题的一部分。

若用户提供准确片名，优先用短、清晰、对比充分的文字；若文字生成无法满足精确可读性，先交付无字 key visual 或提醒用户选择可编辑排版工作流。不得用乱码、小字墙或伪汉字掩盖错误。

### 标题三态决策

| 文字事实与精度要求                                                        | 正确交付                                                                           |
| ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 未提供可核验片名，或用户只需要视觉方向。                                  | 生成 **无字 key visual**，在创作说明中描述标题应占据的区域和与画面的关系。         |
| 片名简短，且生成工具可稳定生成用户提供的精确文字。                        | 在单图中使用一个主标题；标题必须作为构图动作，而不是额外贴字。                     |
| 片名较长、需特定字形/品牌字、需要多行事实信息，或本次实际成图文字不准确。 | 生成无字 key visual + 一份标题区域、面积、对齐、字图关系说明；转入可编辑排字流程。 |

## 6. 色彩、人物与形式语言

先确立明暗结构，再确定色彩。使用一条主色温逻辑（冷、热、灰、低饱和或高对比），至多一处结构强调色；强调色必须标记一个人物关系、物证、出口、伤口、警示或光源，而不是装饰。

| 类型事实               | 可用语言                                     | 默认禁止                                        |
| ---------------------- | -------------------------------------------- | ----------------------------------------------- |
| 亲密 / 文艺            | 呼吸感空场、触感细节、低对比、局部暖色。     | 脏褐滤镜、假胶片刮痕、无意义忧伤姿势。          |
| 悬疑 / 罪案 / 心理     | 阻断视线、压迫透视、局部可疑物、受限光。     | 默认雨夜、霓虹、血迹、连环证据墙、恐怖化。      |
| 运动 / 压力            | 一个身体动作、被压缩的空间、速度或汗水证据。 | 漂浮人头、励志口号、游戏战队视觉。              |
| 历史 / 制度 / 地方题材 | 空间秩序、材料、礼制、物证或真实时间痕迹。   | 自动书法、印章、龙凤、古建、泛化国潮。          |
| 科幻 / 奇想            | 设定中唯一改变日常尺度/规则的可见证据。      | 蓝紫霓虹、宇宙星云、盔甲、科技 HUD 的默认堆叠。 |
| 家庭 / 喜剧 / 成长     | 角色魅力、关系节奏、明亮但节制的色彩。       | 为“高级感”强行压成暗黑、孤僻或成人惊悚。        |

人物可使用授权剧照、用户提供的角色描述或原创虚构角色。需要保真时保留身份、种族/年龄/服装、姿态和关系；没有用户提供的权利或细节时，不使用现实明星或可识别公众人物。

## 7. 把电影命题写成画面指令

把影片身份、视觉命题、底图空间、人物或物证、标题策略、色彩媒介和事实边界组织成一段清晰的图像指令。不要堆类型词、名导演名演员、真实海报名或无效“cinematic”形容词；顺序和篇幅根据当前故事决定，不使用固定段数或字符范围。

在生成前问：**移除标题，底图仍在讲电影吗？移除图像，标题还在参与冲突吗？把某一元素换成另一部片也能成立吗？** 三问中任一答案失效，重选母题而不是增加装饰。

## 8. 质量门与定向修改

生成前检查 Prompt，用户提供成图后再评估。每轮仅处理一个已观察到的失败。

| 质量门                                                   | 未通过时的定向修改                                                                 |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 缩略图首先读到一个清晰母题与情绪，而不是许多“电影元素”。 | 删除次要人物、道具和装饰，放大或压缩唯一母题。                                     |
| 海报传达这部影片特有的冲突，而不是任意类型的通用截图。   | 以故事中的物证、空间关系或人物动作替换泛化符号。                                   |
| 类型承诺仍然成立。                                       | 让色彩、人物尺度和构图动作回到观众应先感受的体验；不要用统一暗黑滤镜。             |
| 标题与图像共享承载面或遮挡关系；无字版本亦独立成立。     | 重设文字坐标、底图空场与对比，不把标题悬浮压在中心。                               |
| 文字只包含用户确认的事实，且主标题清楚可读。             | 移除所有未经提供的日期、署名、奖项、评论、Logo和密集小字；文字不准时改成无字底图。 |
| 授权剧照/参考图被转化，而未被临摹。                      | 改变人物关系、动作、道具、空间骨架或完整配色，保留的只应是抽象视觉逻辑。           |
| 人物/物件没有变成浮头拼贴、游戏封面或商业广告 KV。       | 恢复物理光线、空间接触、遮挡和叙事层级；保留一个主焦点。                           |
| 色彩、纹理和媒介感服务叙事，且无默认套路。               | 删除电影颗粒、雾、霓虹、书法、云层或纸纹，只保留与命题有因果关系的一种形式语言。   |

## 9. Golden Eval

在认定 Skill 稳定前，至少测试六种故事。每张须同时通过“母题可读、冲突具体、类型守恒、图文一体、无伪造信息、无模板性余项”。

| 测试项目           | 主要验收点                                             |
| ------------------ | ------------------------------------------------------ |
| 两人关系文艺片     | 用距离/物件显示关系，而非两张漂亮人像并排。            |
| 制度或法政悬疑     | 让空间与物证形成压迫，不造奖项、审讯 cliché 或小字墙。 |
| 运动压力短片       | 一个身体动作与空间阻力先于口号被读到。                 |
| 家庭/喜剧/成长片   | 保留温度与角色能量，不被强行处理为暗黑文艺。           |
| 世界观/冒险/科幻   | 只选一个设定证据，避免末日云、盔甲、宇宙、军队的堆叠。 |
| 地方历史或传统题材 | 用真实材料、秩序或行为承载文化，不以符号拼贴替代。     |

## 10. 硬性避免项

避免已存在电影、剧集、游戏、海报或在世设计师的可识别风格复刻；参考图的原人物关系、动作、道具组合、构图骨架、标题字形和完整配色；真实或伪造的电影节桂冠、发行方、片商、评论引语、奖项、评分、日期、演职员和版权行；无授权名人肖像；默认浮头群像、数字战队、游戏封面、旅行广告、电视剧剧照、商业 KV；空洞的暗黑滤镜、重 HDR、脏雾、胶片划痕、霓虹、血迹、宇宙、书法、印章、国风符号、飞鸟、雨夜；繁杂小字、乱码、Logo、水印、签名和 CTA。
