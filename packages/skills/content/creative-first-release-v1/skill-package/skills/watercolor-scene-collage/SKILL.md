# 实景拼贴-水彩

上方是原照片，下方是从同一张照片提炼出的淡彩水彩速写微缩小品。保留最值得观看的重点与必要环境，而不是把整张照片缩小后完整重画。让真实摄影与安静的手绘小景形成清楚的对照，像把一次观看缩小、轻轻放在水彩纸上。

每张照片分别制作一张独立作品，不混合不同照片。没有源照片时先请用户上传，不虚构原片。风景、街道、建筑、室内或其他场景均从当前照片读取，不预设山、水、树或风车，也不把它们添加到不相干的照片里。

## 一、上下对照结构

默认 3:4 竖版，明确分成上下两区，高度各占约 50%，以干净的水平边界分开。上半区是真实摄影，下半区是浅米白、奶油白或象牙白水彩纸，整体干净、安静、有设计感。用户明确指定其他竖版比例时保留上下对照与微缩小景的关系。

上半区直接使用原照片，尽可能保留原有构图、主体位置、环境、色彩、光线、比例与自然摄影质感。不重绘、不插画化、不卡通化，不增强对比或饱和度，不加水彩滤镜、纸纹或文字。只作必要的等比画幅适配，不拉伸、不扭曲，也不为了铺满画幅裁掉关键主体或关系。无法兼顾画幅与关键内容时先说明裁切取舍，不擅自扩出新场景。

原片曝光与白平衡也应保留：夜景、逆光剪影和高调场景不是默认瑕疵，不自动把上半区调成统一亮度。先判断下半区要提炼的主体和关系在源片中是否可读；若意外欠曝或过曝已遮住关键证据，说明限制并请用户换图或明确允许先修片，不悄悄提亮、压暗或编造失去的细节。成图后以原片核对摄影区的亮暗与高光层次。

上半区完整保真是视觉目标。一次生成也可能改变原图细节；若用户要求逐像素不变，必须使用能保留原图像素的合成方式，不能把文字要求当作像素保真的保证。

## 二、从原照片提炼小景

先找这张照片的视觉重点及最有辨识度的特征。重点可以是人物、物件、建筑、地貌或一次互动，不按题材预设主角；前景不必都是重点，远景也不必都是可以删除的背景。保留被选择元素之间关键的大小、位置、前后、遮挡与方向关系，不要求完整重建近景、中景与远景。

环境按作用取舍：帮助识别场景、解释动作或支撑、建立必要尺度和空间关系的部分值得保留；删除后仍不影响这些关系的部分可以不画，或只用少量分离的笔触提示。省略环境不等于改变事实，不移动保留的元素来编造新关系，也不把主体孤立成与原片无关的抠图。

下半区可以概括细节，但观者仍应认得出它来自上半区的这张照片。保留决定场景身份的轮廓、必要空间关系和自然色彩关系；有意义的人物、动物或小物件保留其数量、姿态和位置，用概括形体表达，不用通用图标替代，也不凭空添加叙事角色。

主体是纸面中央略偏下的一幅微缩手绘小品，整体约占下半区可见面积的 30%–45%。这是构图尺度参考，不是必须涂满的面积指标。四周保留大片连续空白，纸白也进入小画内部，在元素间隙和次要区域与外部空白连通。可以用纸白承担空气和未描绘的环境，不用连续背景色块把所有元素包成一幅完整插画。微缩感来自小尺度与大留白，不是三维模型、立体沙盘或玩具场景。

## 三、淡彩水彩与速写笔触

采用轻柔淡雅的水彩铺色、少量细腻速写线与概括式提炼。保留的形体以少数透明浅色块建立，识别重点可用松弛细线或稍明确的笔触点出，辅助环境更疏、更轻。背景的简化来自省略内容，不只是把完整背景画淡；不勾满每一个轮廓，不用浓黑线包住全部物体。

浅色铺染、自然颗粒、细致纸纹与局部留纸白共同形成手工感。水彩纸的肌理应可感知但克制，只出现在下半区，不脏、不厚、不做重阴影。小景边缘可有自然的干湿笔触与轻微晕染，整体轮廓和层次仍要清楚，不糊成一团。

环境需要帮助识别或交代空间时，选择最有效的局部轮廓、浅色块或断续笔触即可，不因为原片中存在某种景物就逐项描绘或连续铺底色。只有承托或定位确有必要时才提示地面；留下的环境与主体形成可读的关系，其余交给纸白，不添加照片里没有的景物。

不要复杂精细插画，也不要把全部细节删成几个空泛色块。只在最能认回照片的部位保留细腻观察，其余松、轻、简。

## 四、色彩与纸面

水彩色调参考原图的自然关系，再进行简化、淡化与低饱和处理。保留冷暖和层次，呈现透明、柔和、透气、轻微脱色的淡彩感。浅蓝、灰蓝、灰绿、橄榄绿、米黄或浅棕都只是原片对应颜色的可能表达，不是固定色板。

浅色不等于灰蒙蒙或过曝。保留足够的局部色差，使主要轮廓与空间关系可读；黑白原片不自动虚构鲜艳色彩。下半区纸色自然偏暖，不过黄、不仿旧、不用复杂背景填空。

淡彩不要求所有元素平均淡化。最有辨识度的局部颜色和明暗可以比辅助环境明确，仍保持水彩的轻透感；不要为了减轻背景而同时削弱主体。

上下联系由同源场景、构图层次和色彩关系建立，不需要跨界线条、手绘小人、额外剪贴、撕纸轮廓或装饰物来解释。

## 五、文字取舍

默认无文字，让留白与水彩小品成为重点。用户需要且提供了地点、日期或短句时，可在下半区偏左的留白处放极小、克制、清楚的手写文字，不抢主体；位置可随构图微调。

不猜地名或拍摄日期，不编旅行经历，不加大标题、宣传口号、署名、印章或水印。用户要求纯图时完全省略文字。

## 六、成图质量检查与局部修改

生成前决定原图中要保留的重点、必要环境、可省略信息与淡彩表达；只有看到成图后，才能判断效果是否成立。

- 上半区被重绘、擅自调亮调暗、丢失高光层次或出现纸纹：先恢复真实原照片，其余设计保持不变。
- 下半区像另一处风景：恢复原片最有辨识度的轮廓、位置与层次，不先增加装饰。
- 小景尺度太大：缩小并回到中央略偏下，恢复四周连续留白。
- 小景内部太满、背景像完整场景复刻：先删除无作用的环境、连续底色和重复纹理，让纸白进入内部；不要仅整体缩小或把背景模糊化。
- 简化后失去身份、动作、支撑或空间关系：只恢复必需的环境线索与关键接触，不把整个背景补回。
- 颜色过浓或线条太密：减轻铺色和勾线，仅保留局部识别重点；不要连上半区一起褪色。
- 过度简化、层次糊掉：恢复少量关键轮廓和冷暖色差，不把所有细节补满。
- 纸面过黄、纹理粗重：换成浅象牙白与细致水彩纸纹，不加边框或重阴影。
- 文字抢画面或出现虚构信息：缩小、纠正或删除文字，不用文字替画面建立上下联系。

每次只修最影响结果的一项，其余保持。避免颜色过浓、主体过大、细节过满、背景复杂、商业旅游海报、卡通化、过度写实复刻、三维模型、装饰堆叠与上下两张无关画面。最终下半区应是一幅安静、细腻、微小地放在纸面上的淡彩水彩小画。
