# 极简拼贴：记忆转译式双联海报

把当前上传的单张授权照片做成一张独立的艺术出版物页面。它不是旅游海报、杂志封面，也不是「照片＋插画」的简单叠放。

**核心命题：不要重新画这张照片，而要重新记住这张照片。**
上半部分保存「相机看见了什么」，下半部分保存「多年以后，记忆还留下了什么」。

三条最高原则：

1. 上半是真实摄影，下半是被压缩的记忆，二者是时间上的双联，不是尺寸上的复制。
2. 下半只由 3～5 枚印章色块和 1 枚两行文字印章构成，全部元素必须能回溯到原图或原图情绪。
3. 留白优先于丰富，构图准确优先于纹理丰富。图形可以粗粝，设计必须精确。

一张照片只产出一张作品，不同照片的主体与颜色不得混用。下文的步骤是观察与判断的路径，不是填字模板。

---

## 1. 成品应该长什么样

先建立目标画面，再看所有约束。

- **第一眼**：一张安静、宽松的米白纸页，下半部分几个粗粝的大色块和一小段铅字印痕在大片空白中形成一个平衡的整体。
- **第二眼**：意识到色块的颜色与走向来自上方照片，文字的位置与色块彼此呼应。
- **第三眼**：发现下半部分并没有复制照片，只留下了几个形状、几段颜色、一个方向、一个距离、一句话。

参照物：Corita Kent 与 Josef Albers 的丝网版画平涂边缘、艺术家手工书内页、摄影诗集的对页排版。

关键词：quiet、restrained、memory-like、sparse、poetic、hand-printed、multi-color stamp assemblage、two-line letterpress caption、text as composition element、large negative space、artist-book、editorial art print、tactile、precise、fragmentary、abstract but recognizable。

## 3. 上半部分：摄影锚区

最大程度保留原照片：主体、主体数量、姿态、真实比例、空间关系、透视、光线逻辑、拍摄方向与环境结构。

按需要允许：轻微裁切、适度构图优化、轻微曝光与色彩平衡、非常克制的艺术摄影调色，必要时自然延展天空/地面/水面。原片若已有成熟后期和清楚的光色层次，保持原样，不为统一风格再次调色。

曝光以原片的拍摄意图和主体可读性为准，不把夜景、逆光剪影或高调场景统一调成中间亮度。仅当意外欠曝或过曝遮住主体、面部或关键关系时，才轻微平衡受影响的局部暗部、高光与白平衡；保留光源方向、天空和浅色物体层次，不用全局提亮、重 HDR 或磨平阴影来制造“正常曝光”。源片已丢失的细节不保证靠调色恢复，不补造不存在的事实。

需要轻修时，先确定可见问题和受影响的部位，再只改那里；未受影响的肤色、衣物或物体固有色、材质纹理和背景光色继续以原片为准，不因一处欠曝或偏色给整张照片套统一滤镜。

上半部分只负责「真实记录」，不承载任何文字或图形。

---

## 4. 下半部分：被压缩的记忆

### 4.1 概念

想象一个人多年后回忆这张照片：他不会记得每一块石头、每一扇窗、每一片云，只可能记住一个轮廓、一条方向、一个主体、一段颜色、一个空间关系、一处光。下半部分表现的正是这种残留。

### 4.2 生成前的内部分析（按顺序完成）

1. **第一视觉锚点**：如果只能记住一个东西，留下什么（山峰、人物、建筑、树、河流、道路、桥、塔、窗、缆车、动物、特殊轮廓）。
2. **第二视觉关系**：锚点与什么构成关系（人物与相机、缆车与钢索、建筑与倒影、山与远山、花瓶与圆窗、河流与地平线）。
3. **主导方向**：S 曲线、水平线、对角线、山脊线、道路、河流、树枝、电缆、倒影轴、光线方向。
4. **主导几何**：圆、矩形、梯形、三角山形、长条、S 曲线、不规则色块、垂直标记、水平带、框景。
5. **颜色记忆**：从原图提取 2～4 种主色，而非复制全部颜色。
6. **删除 75%～95% 的信息**。
7. **压缩为 3～5 个视觉形状**，仅在识别确实需要时允许第 6 个。
8. **规划文字印章的位置**（见第 5 节）——文字与色块同时进入构图，不在最后补加。

### 4.3 删减与压缩

主动删除或合并：重复树木、叶片与草地纹理、碎石、小型建筑、窗户、复杂立面、远处人物、重复花朵、山体纹理、水面细波、复杂倒影、云层细节、道路细节、真实阴影、次要背景。

量化参照：

- 30 棵树 → 1～2 块深绿/灰绿印章形植物块
- 20 栋房子 → 3～6 个小型几何建筑块
- 几十朵花 → 1 条枝干 ＋ 2～5 个代表性花形
- 复杂山脉 → 2～4 个山体印模，不描绘岩石纹路
- 栏杆 / 栅栏 / 立柱 → 保留节奏与透视韵律，压缩为若干代表性立柱，不逐根描绘

压缩后的所有形状必须保持原图的朝向、姿态与方向：不得镜像、不得颠倒、不得翻转；桥还是原来的走向，人还是原来的姿态，塔尖还是朝上。

题材专项裁决：

| 题材                      | 保留                                                     | 删除                                     | 印章方案                                                                                                      |
| ------------------------- | -------------------------------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 山川 / 雪山 / 戈壁 / 丘陵 | 山体总体轮廓与山脊节奏                                   | 岩石纹理、沟壑、碎石、真实阴影、地质纹路 | 2～4 个大色块（深灰主山、灰黑次山、淡蓝远山、浅土黄地面），内部仅留极少裂隙与墨层破损；远看像山，近看只是色块 |
| 建筑                      | 巨大体块、水平关系、平台、入口、倒影、最重要的几何方向   | 窗户、立面纹样、砖块、栏杆               | 2～4 个大几何印章；倒影压平为一个暗色色块                                                                     |
| 河流 / 道路 / 灯带        | 方向（S 型、折线、消失点、连续引导）                     | 周围环境                                 | 可适度夸张曲线使其成为下半的主结构                                                                            |
| 花卉 / 植物               | 1 条最具代表性的枝干 ＋ 2～5 个花/叶形                   | 密度                                     | 墨刷、负形、剪纸或单/双色压印，重轮廓与方向                                                                   |
| 人物 / 动物 / 单主体      | 姿态、动作、方向、轮廓；与物体的关系（如摄影师＋三脚架） | 面部、衣服纹理、复杂明暗                 | 一个小型深色视觉锚点                                                                                          |
| 星空 / 夜景               | 银河方向、少量散点星                                     | 逐颗星星                                 | 银河压缩为一条纵向/斜向颗粒印章带；夜空转为深蓝/灰蓝/紫灰/墨黑，暖色灯光为唯一高饱和强调                      |

### 4.4 多色印章语言

正确过程：真实照片 → 删除绝大多数信息 → 拆成几个记忆单元 → 每个单元设计为独立印版 → 用不同墨色分别压印 → 通过错位、重叠与留白重新拼成记忆图像。

- **印模数量**：3～5 枚主要印模，每一枚对应一个视觉形状。
- **墨色数量**：2～4 种，推荐 1 主深色 ＋ 1 环境色 ＋ 0～2 辅助色（如炭黑＋灰蓝＋土黄＋暗绿，或深墨绿＋靛蓝＋灰褐＋橙红）。每种颜色承担一个角色：深灰＝主山体、蓝＝远山/河流/天空记忆、土黄＝地面、暗绿＝植物、橙红＝原图确实存在的暖光或路径。
- **颜色记忆转移**：颜色服务于记忆而非还原。大面积蓝天可转移到远山或一条抽象色带；夕阳橙可压缩成一道橙色印痕；树林绿可成为一个深绿大色块。
- **压印质感**：允许轻微压印不均、缺墨、干边、少量孔洞、微弱颗粒、极小套印错位、边缘轻微破碎。目标是「像人工压印」，不是「像数字噪点滤镜」，整体不脏。
- **印刷技法轮换**：每张照片从以下主技法中选择一种并在本张内统一：撕纸拼贴（纸层带白毛边）、干笔擦、负形线描、网点半调、平涂墨楔、点彩压印。相邻的不同照片必须轮换主技法，不允许每张都是同一种质感。

### 4.5 构图与留白

- 下半部分保留 70%～82% 空白纸面；色块与文字合计占 18%～30% 的视觉面积。留白计算须把文字印章计入图形面积。
- 空白本身就是设计。图形应像一段记忆、一枚残留印痕，而不是完整场景。
- 可用构图：中央孤岛、横向窄景、左重右空、右重左空、对角线引导、框景、极小主体＋巨大留白、单笔触符号、层叠山体。不同照片必须采用不同构图，风格统一、构图不机械统一。
- 画面重心由色块与文字共同决定，不允许色块居中而文字孤悬角落。
- 每个色块必须与水平线、主色块或对角线形成明确的结构关系（落地、压边、呼应、延长），禁止任何色块孤立漂浮在空白中。

## 5. 文字印章（必需元素）

下半部分**必须**包含且仅包含一组两行英文文字。它是构图中一枚与色块同等地位的「文字印章」，不是海报标题，也不是可选注释。缺少文字即判定为不完整作品。

### 5.1 排版

- **两行**，每行 2～6 个英文单词；第二行明显短于第一行，或与第一行错位起始，形成节奏。
- 字体：小型文学衬线体（Garamond、Caslon 类旧书 serif，或轻打字机 serif），字距略拉开。
- 字号：以 A3 打印约 9～12pt 为参照——清晰可读，但不与色块争主次。
- 墨色：使用下半部分已有的最深一色（炭黑、深墨绿、靛蓝），带极轻微的铅字压印不均，与印章质感统一。

### 5.2 构图关系（三选一，由照片决定）

| 关系     | 做法                                                                      | 适用                 |
| -------- | ------------------------------------------------------------------------- | -------------------- |
| 对位平衡 | 色块偏一侧时，文字落在另一侧空白的视觉重心，形成对角呼应                  | 左重右空 / 右重左空  |
| 延线接续 | 文字基线与照片的地平线、山脊线、河流方向的延长线对齐，成为方向关系的终点  | 有明确主导方向的题材 |
| 托底落款 | 文字紧贴主印章下方约 1 个字高处，像版画下缘的题记，与色块构成一个整体轮廓 | 中央孤岛 / 单主体    |

文字与最近色块之间至少保留 1 行字高的呼吸，但两者在视觉上应被读作同一组元素。

### 5.3 文案

从照片情绪生成，两行之间要有转折或呼应，不直接描述画面。

| 避免                                      | 参考                                       |
| ----------------------------------------- | ------------------------------------------ |
| Beautiful mountains. / A peaceful sunset. | The mountain kept its shape. / We did not. |
| A man taking photos.                      | Same winds, years later. / Further still.  |
| The river at dusk.                        | What the light left / was enough.          |

用户提供原文时逐字使用，仍按两行排布。

## 6. 纸张与纹理

- 纸面：温暖象牙白、米白、自然棉纸或无涂层艺术纸，干净、柔和，允许极轻微纸纤维、细小纸点与轻微色差。
- 纸边：仅在整张作品最底边允许极浅、不规则的纸纤维毛边，像手工艺术纸自然裁切，不是刻意做旧。
- 纹理配比：90% 清晰构图 ＋ 10% 手工印刷缺陷。若纹理开始抢注意力，降低纹理——构图优先于纹理。

---

## 7. 统一禁令

全文禁令集中于此，其他章节不再重复。

**上半部分**

- 重绘、卡通化、插画化、油画化、动漫化、明显滤镜、过度 HDR
- 改变主体结构、添加不存在的重要物体
- 任何文字、图形、装饰

**下半部分**

- 成为照片的缩小版、描摹版、简笔画版、完整风景版画或滤镜版
- 统一黑色线稿；照片完整重绘后加颗粒的「伪印章」
- 几十个小印章、重复方块、红色图章堆叠、印章图案墙
- 新增原图不存在的太阳、月亮、红色圆、鸟群、印章符号、建筑、塔、人物、车辆、树、桥、道路、山、花——尤其不为「东方感」加红日，不为「设计感」加装饰圆
- 严重颗粒、大面积噪点、重度木刻纹理、密集刻线、满屏破损
- 脏旧报纸感、污渍、发霉、折痕、烧边、四周撕裂

**文字**

- 大标题、中文标题、竖排大字、多组文字、多个角落文案、杂志信息块、品牌排版
- 只有一行或超过两行；字号大到与色块争主次；字号小到不可辨读

**结构**

- 粗边框、胶带、装饰分隔线、模块框架

## 8. 质量自检

生成前核对目标，成图后按实际画面逐项检查：

- [ ] 上半仍是真实摄影，无文字无图形
- [ ] 上半主体可读，曝光与色彩仍符合原片光线意图；无故压暗、泛白或死白高光需只修摄影区
- [ ] 下半只剩 3～5 个主要视觉形状，每个可回溯到原图
- [ ] 采用多色独立印章拼凑，而非统一线稿或滤镜
- [ ] 下半留白 ≥ 70%（含文字面积）
- [ ] **存在且仅存在两行英文文字**，清晰可读
- [ ] **文字与色块构成明确的构图关系**（对位 / 延线 / 托底），二者共同决定画面重心
- [ ] 无原图不存在的强符号
- [ ] 纹理未抢走构图注意力
- [ ] 若主体为山：整体轮廓可识别，内部已高度抽象
- [ ] 第一眼看到的是「几个安静的色块与一段铅字」，而不是「一张重新画的照片」

若需修改，优先修复最影响主体辨识、留白张力或文字构图关系的一处。

**纠正速查**：像照片缩小版 → 再删 40%～60% 细节、压平透视、合并色块；变成完整风景画 → 只留 1 主体＋1 方向＋1 关系；印章碎片过多 → 减到 3～5 枚；留白不足 → 图形缩小 20%～40%；文字缺失或悬空 → 回到 4.2 第 8 步，按 5.2 重新定位。

---

**最核心的一句话：上半部分记录这个地方曾经是什么样，下半部分只留下这个地方后来被记成了什么样——以及那时会说的一句话。**
