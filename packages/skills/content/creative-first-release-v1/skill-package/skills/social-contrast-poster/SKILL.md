# 日常反差海报

把生活素材做成一张**有观点的社交视觉**，不是替照片加贴纸，也不是把一句网络热梗压在图片上。

每张作品只完成五件事：**一个真实证据、一次意义反差、一种语气机制、一条视觉层级、一条隐私边界。** 观者应先看懂照片或物件，再在标题/关系中发现第二种解释；如果反差无法被理解，就不要强做幽默。

## 2. 先发现内容，不解释照片

先在内部建立 Contrast Card，不向用户展示。

| 字段       | 必须回答的问题                                                                               |
| ---------- | -------------------------------------------------------------------------------------------- |
| 真实证据   | 这组素材中哪一个主体、动作、物件、现场或细节最不可替代？                                     |
| 表层读法   | 观者第一眼会以为这是什么？例如等红灯、喝咖啡、宠物睡觉、拖行李、早餐迟到。                   |
| 第二层读法 | 它实际上能被读成什么状态/关系？例如临时加载、等待系统、轻度故障、被日程追赶、家庭资源失衡。  |
| 反差来源   | 是身份错位、功能误认、尺度错配、正式语气、时间错位、冷静观察还是图文反讽？只能选一个主机制。 |
| 分享意图   | 自我状态、轻观察、生活事故、宠物关系、旅行余波、人物关系或轻纪念，七选一。                   |
| 保护锚点   | 哪些人物、物件、文字、场景关系或私密信息必须保留、隐藏或不被改变？                           |
| 删除清单   | 至少删去两类：重复素材、无关道具、广告标识、低清截图、装饰性贴纸、重复小字或无关背景。       |

将主题写成一句明确关系：

`这条内容不是在讲 [表层读法]，而是在讲 [第二层读法]；用 [真实证据] 让 [反差来源] 一眼成立。`

例如：`这条内容不是在讲等红灯，而是在讲一个城市如何把所有人暂存三十秒；用红灯和停住的人群让“等待模式”成立。` “好笑、松弛、打工人、发疯、有梗”不能代替第二层读法。

## 3. 选择一种内容语气

语气来自真实素材与用户意图，而不是固定人设。每次只选一种主语气；辅助文字不得改变它。

| 语气机制     | 如何制造反差                                       | 适合的真实证据                                   | 应避免                                         |
| ------------ | -------------------------------------------------- | ------------------------------------------------ | ---------------------------------------------- |
| **功能误认** | 把物件重新定义为一个荒谬但可理解的临时工具。       | 咖啡、雨伞、行李、充电线、零食、门票。           | 与物件毫无关系的职位梗或夸张设定。             |
| **制度错位** | 用简短、一本正经的系统/报告/流程语言描述日常状态。 | 排队、通勤、宠物行为、收纳失控、小事故。         | 虚构真实凭证、订单、数据、组织或具体人物评价。 |
| **尺度失衡** | 让一个小细节被当作大事件，或让大环境被小证据戳破。 | 一滴咖啡、空座位、破损物、巨大的行李、微小的人。 | 夸张到无法从照片读出因果。                     |
| **时间错位** | 让现在的动作像提前结束、卡住、延后或反复发生。     | 凌晨办公室、迟到早餐、旅行返程、夜街、等待。     | 每次都用“摆烂/不想上班/发疯”替换观察。         |
| **冷静观察** | 以克制标题让照片显出轻微荒谬或情绪。               | 强氛围街拍、室内角落、自然场景、人物背影。       | 强行制造段子、贴满标签或解释太多。             |
| **图文反讽** | 画面与短标题在情绪、身份或承诺上形成可理解的反向。 | 自拍、双人合照、旅行、食物、聚会。               | 贬低外貌、关系、职业或私人境况。               |

## 4. 选择一种画面承载方式

先判断素材本身的强度，再选结构。不要为了展示拼贴而拆碎一张已经成立的照片。

| 画面承载方式   | 选择条件                                                | 必须建立的关系                                         | 视觉比例                                        |
| -------------- | ------------------------------------------------------- | ------------------------------------------------------ | ----------------------------------------------- |
| **人物状态页** | 人物/双人关系是绝对主体，用户要表达“我/我们现在怎样”。  | 人物与标题前后穿插；一件源生物证说明状态。             | 人物 45–70%；标题 15–28%；从属物 0–2 个。       |
| **碎片关系页** | 有 2–6 个共同指向同一生活问题的物件、宠物、截图或票据。 | 一个主物 + 至多三个证据块，全部服从同一系统隐喻。      | 主物 28–45%；文字 12–22%；留白/结构区至少 20%。 |
| **现场改义页** | 单张照片的构图、事件或氛围已足够强，不应被切碎。        | 原图保持完整；一句标题改变观看角度；一处源生视觉强调。 | 原图占完整画面；标题 18–38%；从属标签 0–2 个。  |

素材模糊或主题不清时，优先用“现场改义页”或先给角度，不要伪造丰富拼贴。碎片关系页中的物件、截图与标签必须来自用户素材或其可见关系；不得新增无关的主对象。

### 碎片关系页：受控证据密度

当反差确实需要多个生活证据才成立时，允许 **3–5 个**物件、局部或功能块，而不是机械压到两项。它们必须同时满足：每一项都证明同一个反差；全图只有一个主标题、一个视觉中心与一种系统隐喻；私人文字始终抽象化；在手机缩略图中所有证据仍从属，不能变成等权贴纸墙。

## 5. 背景、标题与视觉层级

一张海报必须有明确的阅读顺序：**真实证据 → 主标题 → 反差落点 → 少量从属信息**。标题不是字幕，而是把照片改义的视觉动作。

### 5.1 背景策略

- 人物状态页：保留人物所在环境的光、色与空间；可清理杂乱背景，但不得换成陌生场景或商业棚拍。
- 碎片关系页：使用干净纸面、单色块或低噪的真实台面/场景作为共同支撑面；背景只负责组织，不承担第二个主题。
- 现场改义页：完整保留原图光线、构图和关键事件；仅在已有暗部、天空、墙、路面、橱窗或留白区安放标题。

### 5.2 标题策略

默认仅使用一个简短主标题，优先 4–12 个汉字或 2–5 个英文单词。用户提供准确文案时，严格使用原文；若无精确要求，可提出原创短句，但不得使用事实性日期、虚构数据、真实机构名或人身攻击。

| 标题动作                     | 适用画面   | 作用                                 |
| ---------------------------- | ---------- | ------------------------------------ |
| 压住 / 被人物穿过            | 人物状态页 | 使状态与人物产生前后关系。           |
| 成为文件栏 / 指示牌 / 系统条 | 碎片关系页 | 让制度错位可见，但不伪造真实凭证。   |
| 沿信号、边缘或透视轴停住     | 现场改义页 | 放大现场里的等待、方向、阻断或速度。 |
| 放在空区，像一句冷静判断     | 强气氛照片 | 保留照片呼吸，用语义而非装饰改变它。 |

小标签不是必需品。只有在它能让反差更容易被理解时，最多加入两个，每条不超过六个汉字。不要自动用英文、日期、坐标、票据号码、价格、二维码、表情包或不明符号填空。

### 5.3 色彩与材料

从源图提取 2–4 个主色，用明暗和尺寸先建立层级；仅使用一处占画面 **3–12%** 的结构强调色，标出真实证据、反差落点或标题动作。不得默认黑黄警示、红章、蓝黑报表、米色撕纸或荧光贴纸。

每张图只选一种形式语言：干净编辑排版、低密度纸本拼贴、复印颗粒、手写标注或数字界面化。手绘箭头、描边、撕边、胶带、网点、便签与印章只能作为从属痕迹，且总量不超过两种；它们必须指出关系，不能用来遮盖没有创意的构图。

## 6. 把反差写成画面指令

把 Contrast Card 中真正相关的决定写成一段清晰的图像指令，说明照片事实、第二层读法、唯一语气机制、主体保护、空间层级、标题动作、色彩形式、删除项和本图特有的避免项。顺序和篇幅由画面复杂度决定，不必套用固定段数或字符范围，也不要把整份 Skill 机械塞进生成请求。

画面指令必须能回答：**如果去掉标题，照片的事实是什么？如果只看标题，第二层读法是什么？两者合在一起，反差是否只需一次理解就能成立？**

## 7. 质量门与定向修改

先检查 Prompt，再检查实际成图。未通过时，一次只修复一个已观察到的问题。

| 质量门                                                      | 未通过时的定向修改                                                     |
| ----------------------------------------------------------- | ---------------------------------------------------------------------- |
| 缩略图先读到一个主体/现场与一个主标题，不是无序贴纸和小字。 | 删除一半从属元素，扩大主物或标题的视觉权重。                           |
| 标题不复述照片，而是完成一次可理解的意义切换。              | 重写第二层读法；放弃不成立的梗，改为冷静观察。                         |
| 全图只有一种主语气和一次反差。                              | 删除第二个笑点、第二套标签或不相关系统隐喻。                           |
| 人物、宠物、产品和原图空间关系仍被正确保留。                | 恢复身份锚点、姿态、花色、物件特征或原图构图；不要新增陌生主体。       |
| 现场改义页仍能读出完整原图，而不是相似的重绘照片。          | 加强原图保留、限制编辑范围、移除碎片拼贴。                             |
| 碎片关系页有一个中心，所有证据都属于同一关系。              | 保留主物与至多三个证据，删除无关标签与装饰。                           |
| 私密文本不可读，幽默没有指向真实个体或脆弱处境。            | 模糊/抽象敏感信息，替换攻击性、诊断性或事实性文字。                    |
| 色彩与材料服务反差，没有默认手账、电商或办公模板感。        | 删除无关贴纸、价格爆炸标、红章、网点和默认色块；只留下一个结构强调色。 |
| 主标题准确、可读；文字不可靠时没有用乱码假装信息密度。      | 减少文字至主标题，或改为无字视觉并在外部提供配文。                     |

## 8. Golden Eval

完成前至少以六类真实输入测试，所有项目必须在“证据明确、反差成立、层级清楚、原图保护、隐私安全、无模板余项”上通过。

| 测试输入                       | 关键验收                                                        |
| ------------------------------ | --------------------------------------------------------------- |
| 第一人称咖啡 / 通勤 / 手机碎片 | 不写“喝咖啡/堵车”，而让一个源生细节支撑功能误认或时间错位。     |
| 宠物 + 家具/账单碎片           | 不把宠物自动职位化；若采用制度错位，必须与真实行为和物件有关。  |
| 一张红灯/街拍/城市照片         | 保留现场完整性，一句标题即可改变观看角度。                      |
| 人像 / 双人旅行照              | 身份、关系、姿态保真；标题不贬低人物，也不变成时尚广告。        |
| 早餐 / 物件 / 小事故           | 一个主物和至多三个证据形成清晰关系，不做电商促销页。            |
| 截图、票据或订单               | 不读取或复现私人文字；只使用经抽象化后的密度/结构与安全的主题。 |

## 9. 硬性避免项

避免“记录美好生活”“氛围感绝了”“仪式感”“松弛感拉满”“谁懂啊”“做自己的光”等空洞陈词；对所有题材套用打工人、摆烂、发疯、KPI、CEO、董事长、报告、故障、系统崩溃、早八、周一等固定词；复述图片、强行黑色幽默、攻击真实人/群体；标题比照片更复杂；无关物件、漂浮贴纸、满版箭头、五种以上标签、密集伪小字、真实/伪造的订单或凭证；换脸、换宠物、广告化人像、陌生场景；电商价签、品牌 Logo、水印、二维码、隐私信息、AI 标签、错误文字和外部账号。
