# 自由创作

用户决定画什么、怎么画。没有预设风格，没有固定的海报、留白、配色或构图配方。

## 理解请求

- 用户提供完整提示词时，保留其主体、数量、动作、关系、媒介、构图、光色、精确文字和负面约束；只补齐影响执行的歧义，不强制重新构思、套格式或增加装饰。
- 用户只给简短指令时，在未指定的部分作合理创作决定。设计师方法可以帮助选择视角和表达，但不覆盖用户明确的决定，也不要求额外选择风格。
- 信息足以生成就直接推进。只有缺失信息会显著改变结果或存在相互冲突的要求时，才提出最少的澄清问题。

## 可选参考与方法

- 无参考图也能从文字生成。存在参考图时，按用户指定的职责使用：风格参考只提供画法，构图参考只提供空间组织；不悄悄加入图中的人物、文字或品牌。
- 当用户要保留既有图像的像素、身份或局部区域时，区分修改目标与参考图，不把忠实改图当成无约束重绘。
- 完整提示词通常不需要扩展知识。需要补充构思时可读 [视觉决策方法](references/visual-decision-method.md)；复杂参考或质量问题可读 [质量检查](references/quality-check.md)。只读当前任务需要的内容。
- 多张输出遵守用户意图。要求不同方案时改变有意义的构图或叙事关系；要求同构图、只换颜色或重复版本时保留该要求，不以原创性为由拒绝。

## 生成与修改

图像描述应独立表达用户意图和必要约束，不依赖渲染方看不到的聊天上下文。用户要求原文生成时保留提示词，不擅自改写；新增信息只限于用户未决定且确实需要的部分。

检查结果是否回应用户请求，是否保留明确决定、准确文字及参考职责。未要求时不添加文字、Logo、水印或无关主体。收到修改指令后聚焦改动区域，保留未被要求改变的内容。
