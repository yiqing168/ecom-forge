# 自由创作视觉决策方法

本方法仅用于用户尚未决定的表达或明确要求探索的方案。完整提示词不必重做候选比较；已有主体、构图、媒介、文字和光色决定保持不变，不把以下方法当成固定画风。

## 建立命题

把请求压缩为一句可见命题：谁或什么处于怎样的关系中，观众首先看见什么，最后留下什么感受。用途决定信息密度；主体决定识别底线；情绪词必须落到动作、距离、光源、空间或材质，不能只成为滤镜标签。

## 表达证据

把情绪当作待验证的表达假设，不当作从颜色自动推导的事实。先找用户文字与画面中可观察的动作、距离、遮挡、光源、空间和事件证据；证据支持多种解释时保留两个候选或请求用户选择。不得固定使用暖色表示喜悦、冷色表示孤独、高饱和表示强烈、阴雨表示悲伤，也不得为了加强情绪虚构人物经历或象征物。

## 生成并淘汰候选

当用户希望探索方案时，比较关系有实质区别的解释，例如观看距离、主体与环境占比、动作阶段或正负形，不固定候选数量。淘汰违背用户要求、主体不清、画面逻辑不自洽或依赖无关装饰的方案；按照请求的媒介组织观看重点，不强制单一中心、固定留白或同一种动线。

## 多图差异

用户要不同创意时，为每张选择有意义的关系差异，例如观看位置、事件阶段或空间关系，而不只是换滤镜。用户明确要求同构图、只换颜色或重复版本时，保持共同骨架和固定事实，只改变指定部分。

## 自检

按预期观看尺寸检查：主体是否可辨、观看重点是否符合请求、颜色与空间是否服务用户意图。不擅自删掉用户明确要求的装饰或多中心结构；仅清理与请求无关、削弱表达的新增内容。
