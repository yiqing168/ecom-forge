# 实景延伸线稿

每张照片分别制作一张独立海报，不多图拼接。从**真实照片 → 元素连续延伸 → 线稿人物互动 → 温柔手写旁白**组织创作；这些阶段是画面判断的方法，不要求逐项输出。

**创作意图：照片里的一处真实元素越过画面中线，逐渐从摄影质感转化为黑色线稿，与纸上的小人物发生一个巧妙、自然的关系。** 上下不是两幅独立画面，观者能从照片中的准确位置顺着延伸看见互动，而不是靠文字猜测它们的联系。

## 画面结构

采用 3:4 竖版，上下两区高度严格 1:1，各占 50%，分界位于画面正中，每个半区为 3:2 横幅。上半区直接使用原始照片，下半区使用简洁的暖白色或象牙白纸面，带极轻微的纸张纤维感与大量连续留白。整体克制、诗意、安静、高级，有编辑感和视觉隐喻。

上半区保留原始照片本身，保持原有主体、人物、建筑、动物、光线、色彩氛围、构图关系与真实摄影质感；不得重绘、模糊、扭曲、拉伸、镜像、重复或随意添加新主体，不在照片上添加线稿、文字或纸纹。仅允许为了适配画幅做少量自然的等比例裁切，或轻微环境延展；延展不得新增主体、角色或为连接而发明实景元素。

曝光也是原片的一部分，不自动把夜景、逆光剪影或高调照片调成同一亮度，也不借“改善摄影”改变上半区。先判断源片中连接元素和关键关系是否可读；若意外欠曝或过曝已使它们无法辨认，说明限制并请用户换图或明确允许先修片，而不是偷偷提亮、压暗或生成原片没有的细节。成图后若摄影区被无故改亮、改暗或丢失高光层次，应恢复原片的光影。

适配画幅时，保留主体与所选元素之间的真实关系。若裁切或少量延展仍无法同时满足关键内容保留与上下等分，应说明取舍，不静默裁掉重要主体或承诺不可能的完整保留。

## 阶段一：选择真实延伸元素

分析当前照片，自动选择一个最适合向下延伸的真实元素。优先寻找方向、边界或形态能够自然接续到纸面的部分，例如道路、小径、河流、海水边缘、湖岸线、船桨、树枝、电线、绳索、桥梁、山脊线、坡地边界、建筑轮廓或倒影；这些只是观察方向，不限定照片类型，也不是题材与动作的固定对应表。

选择依据是这张照片中元素的**准确位置、形状、走向，以及它可以怎样与小人物发生关系**。先找到真实的来源，再设计延伸；不先选一个小人姿势，再随意补一条与照片无关的线。

同时考虑上半区的取景与中线处的连接位置，让所选元素能够自然接续到下半区。不把照片中间悬空的元素假说成已经接触中线，不为了接线而篡改原有主体或空间关系。

## 阶段二：连续转化为线稿

**所选元素必须从照片中的准确位置连续穿过中线，逐渐由真实摄影质感转为简洁黑色线稿。** 在分界处保留对应的方向、轮廓与宽度，让观者看出这是同一个元素的延续。连接中间不能有空隙、错位或重新起笔。

转化在下半区展开，上半区照片本身不动。摄影质感可以沿元素逐渐简化成线条，但不把整张照片做渐变，也不让纸纹覆盖摄影区。无需另外贴一块孤立的照片剪贴，不强制所有元素收窄成同一根细线；保留当前元素使连接可辨的必要形态即可。

延伸形状与路线由当前照片和互动决定。每张照片设计自己的连接创意，不把所有照片都接成同一条绳子、同一道弧线或同一种撕纸轮廓。

## 阶段三：让小人物与延伸互动

默认加入一个小比例黑色钢笔线稿人物，高度约占整张画面的 7%–10%。人物没有清晰五官，服装与道具高度简化，线条纤细、略微不规则、松弛自然；不要画成巨大主角、复杂速写或 Q 版人物。

动作根据照片内容原创设计，例如沿路行走、牵引水流、拉住绳索、站在分岔口、观察远方、推开路径或顺着线条前行。人物比例自然，动作与延伸元素相符；这些只是可能的关系，不按题材固定分配，也不要求每次都制造拉扯、用力或材料变形。

**人物必须与延伸元素有明确、可见的关系。** 拉、托、推或攀爬时，让手脚接触的位置与身体姿态相符；行走或休息时，让路径、落脚点或承托关系清楚；观察时，让视线、朝向与所观察的延伸部位对应。不能只在空白处摆一个与主图无关的小人，也不能让人物无依据地悬浮。

以一处主要互动组织下半区，其余交给留白。尺度、姿态和必要道具服务于这个关系，不复刻完整场景，不堆积多个故事或无关图标。用户明确要求不加人物时省略人物，仍保持实景到线稿的连续延伸。

## 阶段四：温柔手写旁白

根据照片内容与互动生成一句 2–5 个英文单词的温柔手写短句，拼写准确、黑色、小字号，作为情绪旁白而不是主标题。语气轻巧、自然，补充画面的感受，不用长篇解释替代尚未画出的连接。

文字放在互动附近合适的留白里，不压住连接处、人物或重要线条。位置随当前构图决定，不固定角落；字号克制但仍需手机观看可读。用户给出准确旁白时按原文使用；明确要求无文字时省略，不生成伪手写或额外标识。

## 负面清单

禁止上下完全断开的照片与插画、悬浮小人、孤立图标、巨大人物、复杂五官、Q 版动漫、厚重轮廓、密集速写、完整场景复刻、信息图构图、拼贴网格、邮票、边框、水印、手机界面、过黄纸面、过大文字。

尤其避免连接空隙、错位或重新起笔；照片和线稿人物互不相关；为接线随意改动原图；把所有照片套入同一种连接创意；用装饰和旁白掩盖看不见的互动。

## 质量检查与修改

先检查照片保留与连接，再检查人物、文字和留白。纸张与线条漂亮不能抵消上下断开。

| 检查                 | 判断与修改                                                                                           |
| -------------------- | ---------------------------------------------------------------------------------------------------- |
| 画幅与分区           | 是否 3:4 竖版、上下各 50%、分界在正中？修正比例，不改成多格拼贴。                                    |
| 原照片是否保留       | 主体、角色、动作、光色和清晰度是否与原图一致？先修照片变化，移除摄影区的绘画或材质效果。             |
| 连接是否连续         | 能否从照片中的准确位置一直追到纸上的线稿？修正中线处的起点、方向与宽度，消除空隙、错位和重复起笔。   |
| 互动是否明确         | 不读旁白，是否能看出人物在怎样使用、接触或回应延伸元素？修正接触、路径、承托或观察朝向，不只改文字。 |
| 人物与纸面是否克制   | 人物是否约占整幅高度的 7%–10%，细线、无清晰五官，纸面是否有大量连续留白？删去多余细节和孤立道具。    |
| 旁白是否合适         | 是否一句 2–5 个英文单词的准确手写旁白，或按用户要求无文字？修正拼写与位置，避免标题化和过大文字。    |
| 创意是否来自当前照片 | 换一张图是否仍只需换照片、不动下半区？若是，重新选择这张照片的连接元素和互动，而不是复用模板。       |

每轮只改最影响结果的一处，其余保持。纯生成式工具无法保证原照片逐像素不变或文字绝对准确；需要精确保留原片时使用能锁定照片的排版或合成工具，不用提示词承诺工具做不到的保真。
