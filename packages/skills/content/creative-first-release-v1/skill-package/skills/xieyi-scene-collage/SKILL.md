# 实景拼贴·写意纸境

将一张授权实景照片重新组织成具有中国绘画精神的当代纸本作品。摄影提供“实”的证据；纸、墨、设色和留白提供“虚”的延展。目标不是把照片套上水墨滤镜，也不是堆叠山水、印章、祥云、毛笔字等国潮符号，而是让现实在一个明确位置进入纸墨世界。

每张作品只需要建立五件事：**一个实景锚点、一个画面之势、一处实虚转折、一种主纸墨行为、一处方向性留白**。任何额外元素都必须令其中至少一项更强；否则删除。

## 2. 模式选择

默认使用 **当代写意纸境**。在该模式中，把墨、水、吸收、纸纤维、拓印和矿物设色当作材料行为，而不是传统题材的装饰。允许实景、抽象、摄影碎片和纸墨在一个现代构图中并存。

只有当用户明确要求“传统国画、古风、山水、工笔、书法、文人画、古画气韵”时，才使用 **传统笔墨纸境**。传统模式可采用更完整的笔墨与章法，但仍必须保留一个主势、一处实虚转折和足够的呼吸空间。

无论哪种模式，都不得因“国风”自动生成红金配色、祥云、龙凤、古建筑、印章、题字、青花、折扇、灯笼或满版山水。只有源图关系或用户意图需要它们时，才允许以从属碎片出现。

## 3. 读图：先找“实”、再找“势”

在内部建立简短 Scene Card，不向用户展示：

| 要素       | 必须确认的内容                                                                 |
| ---------- | ------------------------------------------------------------------------------ |
| 实景锚点   | 必须保持摄影、使场景可辨识的一个主体、局部或空间证据。                         |
| 空间不变量 | 不得随意破坏的相对位置、透视、路径、轮廓、朝向、光向、地平线或遮挡关系。       |
| 画面之势   | 选择一种最强趋势：上升、下沉、横推、回旋、聚散、对峙、远引、停顿或下压。       |
| 虚处潜能   | 哪一片低信息区域可成为距离、雾、光、隔断、呼吸或未尽之势。                     |
| 转折证据   | 从实景中提取可被纸墨接住的方向、光影、重力、路径、边界、节奏、视线或时间痕迹。 |
| 删除清单   | 至少三类应删掉的次要细节、重复物、装饰冲动或无关纹理。                         |

先写一句可见的画面命题：`让 [实景锚点] 的 [源生关系] 在 [纸墨转折] 后继续成为 [势或空间后果]。`

命题必须描述能被看见的关系变化。例如，“让一束向上倾斜的枝条在失去摄影细节后仍牵住上方的空白”；“安静、诗意、有国风感”不是有效命题。

## 4. 画面建造：实、势、虚、转折

### 4.1 建立主从层级

让一处视觉锚点首先被看见，一处画面之势把视线带开，再让方向性留白接住或抵抗这股势。摄影不必占最大面积，但实景锚点必须在缩略图中仍可读。

| 画面角色 | 工作方式                                                 |
| -------- | -------------------------------------------------------- |
| 实       | 保留一段有摄影细节的主体、空间或光影事实。               |
| 势       | 用一个大方向、质量、笔势、边界或节奏组织眼动。           |
| 虚       | 以未画纸面、浅墨、雾化转印或低密度设色形成有方向的空间。 |
| 转折     | 让摄影在一处边界退成纸墨，或让纸墨从现实的力量中长出。   |

不要平均分配摄影、墨、纸和色彩。不要把留白做成空背景；它必须承担远近、光、隔断、安静、对位或未尽的功能。

### 4.2 设定一处由实入虚的转折

选择唯一主要转折：摄影边缘在局部被纸吸收；真实阴影转为积墨；实体轮廓退为干笔或飞白；路径/光线穿过摄影后变成淡墨方向；局部形体从墨色重新显现为真实细节。

转折必须改变空间、重量、距离、时间或图底关系之一。不得只把照片均匀调灰、简单羽化，或用一团墨云遮住摄影。

摄影和纸墨必须共享一条源生关系。保留摄影的地方应有精确度；进入笔墨的地方应有取舍和材料差异。两者交接处允许不完整，但不允许像数码矩形遮罩、贴纸白边、滤镜渐变或纸片压在照片上。

### 4.3 用一种纸墨行为建立第二层空间

每张图选择一种主纸墨行为；需要时仅加一种从属痕迹。它们必须服务画面之势，而不能独立展示“国画效果”。

| 主纸墨行为  | 可见特征                   | 最适合承担的作用                   |
| ----------- | -------------------------- | ---------------------------------- |
| 干笔 / 飞白 | 断裂、露纸、速度、粗细变化 | 推进、风、骨力、路径、阻断。       |
| 湿染 / 渗化 | 边缘扩散、浓淡层次、吸收   | 雾、潮湿、距离、光的消退、呼吸。   |
| 积墨 / 焦墨 | 重暗、压实、边界凝聚       | 重力、前景、停顿、压迫、锚定。     |
| 破墨 / 叠染 | 两种墨值在局部相遇         | 时间层、光影转折、空间松动。       |
| 拓印 / 转印 | 压印颗粒、擦印、残缺纹理   | 记忆、地表、墙面、树影、历史痕迹。 |
| 没骨设色    | 无硬线的淡色质量           | 花、雾、皮肤、光、温度和柔性重量。 |
| 矿物颗粒    | 干涩颗粒、较不透明的局部色 | 冷暖支点、山石感、夜色或高光。     |

纸性同时只能选一类：清冷生宣式快速吸收、温润熟宣式稳定承墨、棉纸式纤维颗粒、朴素再生纸式哑光，或深色纸上的反白/矿物光。按源图温度、光线、墨值和情绪选择；不得把黄旧纸当成默认签名。

## 5. 设色、形体与个性

默认以墨值和纸色完成主层级。只有在色彩能改变视觉重心、温度或空间深度时，才添加一种克制设色。色彩应来自源图的光、阴影、植物、衣物、天空、地表或情绪张力，并以没骨色团、矿物颗粒、淡染、错位印记或局部提色出现。

不允许最后才贴一个红点、金箔、圆月、印章、色块或笔刷来制造“东方感”。删除色彩后，如果画面关系没有变弱，就不要使用它。

个性不来自固定符号，而来自一次有后果的判断：让近处的真实细节被留白切开；让一条源生路径以干笔冲入虚处；让一块重暗积墨压低原本轻飘的摄影；或让一段现实光线在纸中扩散成未尽的距离。每张图只做一次这样的决定。

## 6. 实景融合与主动删减

保留实景锚点附近的摄影细节、真实色彩、关键透视和源图特有证据。向外逐步减少背景、道具、重复纹理、枝叶、标识、路人、噪点或相近形体；不要因为“写意”而使重要主体不可辨。

将复杂场景压缩为一个主质量、少量方向手势、最多两组从属证据和一处方向性虚空。将密集枝叶、建筑、浪、窗格、人群或地表纹理合并为质量、节奏或可呼吸的间隔，而非逐物写生。

在最终 Prompt 中写出至少三类已删除内容。被删除的内容不得以淡影、装饰线、边角残片或水墨噪点偷偷回到画面。

## 7. 文字与版面

默认无文字、无署名、无水印、无印章。主题不等于可见标题；用户说“关于山、雨、花或城市”不授权把这些字写入图片。

只有用户明确提供要显示的文字，或明确要求文字版面时，才加入一条短文本。必须逐字使用批准文案；不得臆造地点、日期、年份、编号、古诗、名言、题跋、落款、印章或伪书法。

文字必须从属于主势，可作为安静区的轻微停顿；不得与摄影锚点、纸墨主势或设色竞争。需要传统书写感时，先由用户明确要求；否则优先使用克制的现代宋体、明体、无衬线或不带文化符号负担的轻字重排版。

## 8. 把决定写成画面指令

将当前作品真正需要的画面、空间、纸性、笔势、设色、文字和删减决定组织成完整而可执行的图像指令。不要以“高级、意境、国风、艺术感”替代方位、关系、材料和删减。

根据画面的自然逻辑安排这些信息，不强制固定段数、标题、句数、字符范围或逐字模板。指令应明确哪里保留实景证据、哪里进入纸墨，势从哪里开始并指向哪里，摄影如何退入纸面，纸墨如何从现实关系中生长，以及留白承担什么功能；避免项只写本图真正需要避免的失败方向。

## 9. 质量门与定向修改

生成前检查 Prompt；用户提供成图并要求反馈时，再基于实际图像检查以下结果。若用户要求重做，只纠正已确认的一个失败点。

| 质量判断                                       | 未通过时的定向修正                                  |
| ---------------------------------------------- | --------------------------------------------------- |
| 缩略图先读到一个势与一个实景锚点。             | 放大主方向或主质量，删除无关材料痕迹。              |
| 实景仍可辨，空间不变量没有被破坏。             | 恢复摄影证据和关键相对位置，不增加新符号。          |
| 留白带来距离、光、隔断或呼吸，而非普通背景。   | 重新定义留白方向与其对主势的支撑/抵抗。             |
| 实虚在一处关键交接上互相接住。                 | 指定摄影—纸墨转折的轮廓、方向、材料行为和空间后果。 |
| 纸墨表现为一种真实材料行为，不像统一水墨滤镜。 | 保留一种主纸墨行为，删除其余泛化特效。              |
| 新增设色、文字、传统元素均有来源且从属。       | 移除无来源色点、印章、毛笔字、古建或装饰物。        |
| 画面有删减后的气息和整体性，而非元素叠加。     | 再删除一组次要细节，重新平衡重暗与留白。            |

## 10. 硬性避免项

避免水墨滤镜、均匀灰化、照片上盖一团墨云、数码羽化渐变、矩形照片遮罩、贴纸白边、立体纸影、满版国画场景、默认黄旧纸、默认红金配色、默认毛笔字、错误中文、伪古诗、印章、祥云、龙凤、青花、折扇、灯笼、古建筑模板、山水符号堆叠、多个竞争笔法、多种设色、反光金属质感、商业国潮广告、3D、霓虹、电影光效、AI 磨皮、过度锐化、Logo、CTA、水印、签名、虚构年份、日期、地点和长文本。
