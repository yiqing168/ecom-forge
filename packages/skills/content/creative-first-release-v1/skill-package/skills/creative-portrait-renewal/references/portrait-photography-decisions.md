# 人像摄影决策

## 决策优先级

按人物状态、观看距离、动作与空间关系、光线来源、色彩关系、局部光学效果的顺序规划。滤镜、颗粒、炫光和虚化只能加强已经成立的摄影关系，不能挽救空洞姿势或错误身份。

## 人物状态

从原片已有事件中寻找可保留的状态：交谈、回望、整理物件、行走、等待或被环境打断。不得凭空改表情和关键动作。多人画面逐人记录视线、手势、遮挡和相互位置，任何改善都不能交换关系或合并面孔。

## 观看距离与空间

选择能保留身份和事件的最近有效景别。近景要容纳表情与关键手势；中景要保留人物之间的动作链；环境只有在解释人物或情绪时才扩大。大胆裁切不得切掉身份锚点、关系证据或用户指定服装。

## 光线与自然度

每个主光必须有窗、太阳、灯具或环境反射等来源。肤色保持真实层次，避免全脸镜面高光、塑料磨皮和统一模板脸。发丝、玻璃、布料或背景可承受更强光效，主要五官保持清楚。摄影完成度来自可解释关系，不来自把普通人改造成陌生模特。

## 失败修正

身份漂移时先恢复身份和关系，不继续叠加风格；画面平淡时调整观看距离或事件，而不是加滤镜；背景抢人物时降低信息和对比；光效覆盖五官时只收回光效区域。每次只修正一个已观察到的失败。
