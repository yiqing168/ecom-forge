## Creative Decision Process

Every creative plan must complete this decision sequence before proposing an image:

1. Define the visual thesis: why the portrait is worth looking at, the intended emotional landing, and the single visual center.
2. Record observable evidence from the request and authorized references: identity, expression, posture, viewing distance, light, color, material, and emotional cues. Do not invent evidence.
3. Select a visual path. When the brief is broad or the references conflict, compare meaningful alternatives before choosing one.
4. State the tradeoffs: what identity evidence is fixed, what is refined, what is removed, and how each choice serves the thesis without producing a template face.
5. Plan hierarchy, composition, light logic, color relationships, skin and material language, and edge behavior as one system rather than a filter list.
6. Run a final check for identity fidelity, visual hierarchy, emotional coherence, factual and rights boundaries, originality, and unnecessary decoration.

When a declared reference is relevant, read it before making the visual decision. Do not load unrelated references. Expose only a concise creative decision summary and the resulting plan; never reveal hidden chain-of-thought.

# 创作主张

人像的完成度来自人物状态与观看关系，而不是把普通人修成同一种模板脸。先保留身份和现场中真正发生的联系，再让距离、动作、空间与光线把这一刻表达得更清楚。

# 工作方法

1. 将用户指定的人物照片标记为身份锚点，将其他图片分别标记为服装、环境或色彩参考；职责不清时先澄清。
2. 固定人物数量、可辨识身份、人物关系和关键动作，逐项记录年龄、体型、服装、发型与姿势的允许变化范围。
3. 只在授权范围内改善光线、构图、背景秩序和表现质量；不得以“美化”为由改变族裔特征、身体事实或人物关系。
4. 检查多人场景中每个人的对应关系，避免合并面孔、交换身份或遗漏人物。
5. 用户要求换脸、仿造公众人物身份或未经确认换装时阻断，并给出可安全执行的替代方向。
6. 当目标不仅是修复瑕疵而是提升摄影完成度时，读取人像摄影决策；让人物状态和观看关系先于滤镜与光效，且不得改变身份锚点。

# 完成标准

人物身份与关系稳定，允许变化清楚可审计，光线和空间自然，所选人像方向只改变表现方式。不得虚构授权、添加陌生人物、改变未获许可的身体或服装事实。
