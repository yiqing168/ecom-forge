# Gathered Scenes Zine 实景拼贴

把授权实景照片处理为一张安静而有决定性的纸本 zine 海报。作品必须同时是**真实场景**与**编辑后的第二种视觉语言**：摄影提供事实，插画与纸面重排观看。

每张成品必须建立五个可见部件：**摄影锚点、插画正形场、主动负形、单一结构色、可读手撕交界**。纸面不是背景，色彩不是装饰，撕边不是相框。

## 1. 核心原则

优先确保场景身份、主体关系和真实空间仍可辨识。随后把照片的复杂信息压缩为少量大质量、方向手势和留白；不要逐物描摹或把完整照片轻轻淡化到纸上。

令摄影、插画和结构色共享一条源生轮廓、轴线、节奏或场域。插画必须作为可见的第二正形改变整张画的轮廓、重量或眼动，而不是以淡影、残迹或水痕冒充“纸面续写”。

让作品由一个作者性决定主导：**揭示或遮蔽、牵引或阻断、压缩或打开、停留或离开**。把这个决定落实为位置、尺度、轮廓或图底关系；不要用解释性文字、无来源图标或新增物件来表达它。

## 3. 读取源图

在内部提取以下 Scene Card，不向用户展示：

| 要素       | 必须找出的内容                                                      |
| ---------- | ------------------------------------------------------------------- |
| 摄影锚点   | 仍应保持为摄影、使场景可辨识的 1–2 个主体或空间证据。               |
| 空间不变量 | 不得破坏的相对位置、透视、尺度、朝向、路径、地平线、遮挡或轮廓。    |
| 主导手势   | 最强的水平、垂直、对角、曲线、汇聚、视线或运动。                    |
| 重量图     | 暗度、面积、饱和度、孤立、纹理、贴边或人脸带来的重/轻关系。         |
| 源形候选   | 可同时组织摄影、插画和结构色的 1–2 个轮廓、平面、阴影、路径或节奏。 |
| 安静区     | 天空、水面、墙面、地面、雾气或低信息区域。                          |
| 语义最小集 | 去掉细节后，仍能认出这一具体场景的最小形体与关系。                  |

先问：**这张图最值得保留的事实是什么？最值得重排的关系又是什么？**

## 4. 视觉建造协议

### 4.1 先确定层级

为每张图选定一个主导场、一个从属场、一个焦点和一个方向性安静区。平衡视觉重量，而不要平均分配面积。除非源图刻意对称，否则避免无意的 50/50 平分。

选择一个构图起点，并按源图实际重量调整：

| 构图起点          | 摄影起始占比 | 插画的职责                                               |
| ----------------- | -----------: | -------------------------------------------------------- |
| 变形交界          |       30–50% | 将真实主体、路径、阴影或边界跨摄影交界发展成更大的形体。 |
| 底印穿行          |       35–60% | 让低密度插画或色场从摄影后方穿行，并局部穿过摄影。       |
| 摄影锚点 + 扩张场 |       25–45% | 保留紧凑事实锚点，让插画承担更宽的画面重量。             |
| 方向分割          |  55/45–65/35 | 沿真实地平线、视线、路径或结构边进行分割。               |
| 不规则碎片        |       25–50% | 用最大的摄影碎片保留主体，并由一块共享质量连接其他碎片。 |

数字是起点而不是装饰性指标；若它伤害场景身份或眼动，必须调整。

### 4.2 建立抽象地图

对每个插画区域，明确保留、合并、删除、变形和露白：

- **保留**不超过 1–2 个定义性形体或关系。
- **合并**重复树木、栏杆、窗格、浪、人群、枝叶或建筑细节为更大的质量或方向节奏。
- **删除**次要物件、表面描述、背景杂乱和冗余轮廓。
- **变形**一个源生形体为剪影、断续轮廓、几何剪纸、油墨场、半色调或重复印记。
- **露白**必须发生在形体内部或形体之间，用以切开质量、留出呼吸或形成主动反形。

抽象必须保留至少一个源图特有线索。不要把场景完整复印后再加旧纸纹，也不要让空白独自替代第二正形。

### 4.3 形成插画正形场

选择一种主插画语法；最多增加一种从属语法。主语法必须被识别为一个大的视觉决定，而不是很多同等细小效果。

| 主语法   | 适用的源图证据                   | 视觉职责                           |
| -------- | -------------------------------- | ---------------------------------- |
| 剪影     | 人物、树冠、屋顶、船、强轮廓     | 建立一个深色或灰色大质量。         |
| 断续轮廓 | 路径、建筑、栏杆、动作、岸线     | 保留方向与关系，放弃描述性细节。   |
| 场域     | 水、雾、天空、阴影、地面         | 用不规则油墨或半色调大场承载氛围。 |
| 节奏     | 立柱、窗格、浪、枝、台阶、人群   | 将重复元素压缩为有限的间隔和推进。 |
| 剪纸     | 存在明确形状等级的有机或几何形体 | 用 1–2 个裁切形体重排图底。        |

区分**插画影响范围**和**实际印刷密度**。插画可影响约 45–70% 画面，但大多数影响区域应保持未印刷；通常保留 55–75% 的安静，复杂枝叶场景可提高到 65–85%。活跃油墨、剪纸或半色调通常只占整图 15–35%。

使用一块足以改变全图轮廓的主质量、1–2 个从属痕迹和最多一处纹理场。先放大形体，再删除细节。

### 4.4 压缩复杂有机图像

枝叶、花丛或密集自然纹理越复杂，插画越要少：保留一个主质量、1–3 段方向手势、至多两个次级簇和一处稀疏纹理样本。删除约 85–95% 的叶片、细枝和重复印记。

优先保留倾斜、开口、光隙、枝条方向、轮廓压力或质量分布。若缩略图像蕾丝、花边、珊瑚、密集木刻或完整植物插图，继续合并并删减；不要只是降低透明度。

## 5. 结构色

只使用一个新增印刷色。它必须是构图形体，而不是最后贴上的情绪滤镜。照片原有颜色不计入新增色。

先在以下关系中选择一个：安静和声、聚焦对位、温度桥接或源色共鸣。随后指定准确色相、源生轮廓、整合方式、材料、透明度、功能和近似面积。

| 整合方式   | 要求                                                       |
| ---------- | ---------------------------------------------------------- |
| 源形延续   | 将源图中的轮廓、影子、路径或节奏跨交界发展。               |
| 选择性替换 | 将一个真实摄影区域替换为印刷平面，同时保留周围证据。       |
| 底印穿行   | 让半透明、半色调或错版色场在摄影和插画后方并局部穿过两者。 |
| 反形       | 从剪影、间隙、阴影或安静区导出色彩正形或负形。             |
| 方向节奏   | 沿真实视线、路径、栏杆、山脊、岸线或汇聚关系推进。         |

颜色必须同时满足至少两项：来自源图轮廓/位置/节奏；接触或穿过摄影/插画；在交界处变形；重定向眼动或平衡重量；澄清真实主体、空间关系或情绪张力。

不透明色形通常占 2–6%，半透明/半色调/错版底印占 6–15%，大型色场占 10–20%。移除色彩后，若眼动、平衡、图底或摄影—插画连续性没有变弱，重新设计它。严禁游离矩形、补丁、通用圆点、任意亮点和独立笔刷。

## 6. 摄影、纸面与撕边

摄影锚点保持自然色彩、可信纹理、透视和定义性细节。纸面为暖奶油旧纸：哑光纤维、克制雀斑、轻微风化、扫描噪点和无立体投影。纸纹永远从属于插画正形和负空间。

在摄影转为纸面或插画的主交接处，设置一条可见手撕纤维边。交界应有不规则轮廓、狭窄的暖纸纤维带、局部磨损与 1–2 个较强压力点；保持平整扫描感，不出现浮纸或投影。

活跃纤维带通常为短边的 1–4%，并影响可见摄影周界约 35–70%。允许插画或结构色在少数位置跨越、从撕边中生长或从其后穿行；残影、碎屑和颗粒只可服从于这些交接压力点。

不要使用矩形遮罩、均匀白边、贴纸轮廓、装饰性毛边、厚纸阴影、卷角或多层立体纸片。

## 7. 微文字与材质语言

默认采用竖版 3:4 海报、暖奶油纸、选择性木刻/复印/半色调/Xerox/risograph/letterpress/剪纸和一张平整扫描件的质感。不得呈现光滑样机、3D 空间、电影化景深或商业广告层级。

除非用户要求无文字，加入一行从场景中生长的微文字作为眼动休止点。用户提供文字时必须逐字准确；未提供时，可写一行原创短语，不伪造名言或归属。默认英文；中文不超过 8 个字，英文不超过 5 个词。

把文字置于真实安静纸区，并与源图边、撕边、主轴或视觉基线对齐。使用打字机感 letterpress、淡铅笔、磨损印章或干墨之一；保持字小、从属、轻微断墨与纸张吸收。不得添加地址、日期、编号、Logo、CTA、伪编辑元数据或大标题。

## 8. 把决定写成画面指令

把当前照片真正需要的施工信息写成一段完整、具体、可执行的图像指令。它应自然包含画幅与层级、摄影锚点、插画正形场、主动负形、结构色、交接边界、纸面材料和文字决定，但不必套用固定段数或固定标题。对每个大形明确其**方位、影响范围、方向、轮廓和功能**，不要以“有艺术感”“高级”“创意”替代几何和材料决定。

指令必须让人看见摄影锚点、插画正形场、主动负形、结构色和交接边界，而不是只把这些决定留在内部分析中。先读取照片、确定焦点与眼动、提取源形，再选择版式、抽象地图、插画语法、结构色和撕边行为；最后检查它们是否形成同一条视觉因果链。

## 9. 定向修正

按实际成图中已经观察到的问题修改：插画怯弱时放大主质量而不是增加细节；插画过实或过密时合并形体、扩大负形；交界像贴纸时恢复不规则撕裂和露纸纤维；颜色像装饰时让它延续源形或方向节奏；场景失真时恢复空间不变量。一次只处理一个明确失败点。

用户请求修改时，只修复观察到的一项失败：

| 失败             | 定向动作                                               |
| ---------------- | ------------------------------------------------------ |
| 插画怯弱或像淡影 | 放大主质量与影响范围；不要添加更多细节。               |
| 插画过实或过密   | 删除至少一半细节，合并质量，扩大内部负形。             |
| 枝叶像花边       | 压缩为一个主质量、少量方向手势和最多两簇次级形。       |
| 构图无力         | 加大主导场，简化从属场，重建眼动。                     |
| 交界像贴纸       | 恢复不规则撕裂、狭窄露纸纤维和局部材料磨损。           |
| 颜色像装饰       | 以源形延续、选择性替换、底印穿行、反形或方向节奏替代。 |
| 场景失真         | 恢复空间不变量和语义最小集，不增加新元素。             |
| 文字抢戏或失真   | 降低文字尺度/反差，移入安静区或按用户原文修正。        |

## 10. 硬性避免项

避免逐物描摹、全场景复印、逐叶渲染、蕾丝式植物插画、满画面排线、完整细致物件轮廓、填料装饰、通用抽象母题、无来源色块、独立笔刷、任意亮点、构图完成后才添加的颜色、数码矩形遮罩、贴纸白边、均匀装饰毛边、重投影、卷角、密集手帐拼贴、多套竞争插画风格、多种新增色、商业广告层级、Logo、CTA、霓虹、3D、电影化光影、可爱卡通、过度锐化、AI 磨皮、光滑数码字体、错误文字、长文本、虚构归属和水印。

## 11. 质量门

生成前检查最终 Prompt；用户提供成图并要求反馈时，再基于实际图片检查。

| 必须通过的判断                               | 不通过时的处理                         |
| -------------------------------------------- | -------------------------------------- |
| 场景、核心主体和关键空间关系仍可辨。         | 恢复摄影锚点和空间不变量。             |
| 缩略图先读到一个大关系，而不是一组拼贴效果。 | 放大主质量或主动负形，删除从属痕迹。   |
| 插画是解释而不是描摹，且影响足够大区域。     | 重新做保留/合并/删除/变形/露白地图。   |
| 摄影、插画、色彩共享源生关系。               | 用源形替换通用图标、游离色和无关纹理。 |
| 纸面澄清形体，撕边建立材料交接但不是装饰框。 | 收回均匀边缘和散落残留。               |
| 结构色通过移除测试；微文字保持从属。         | 重新设计颜色功能或降低文字层级。       |
| 作品平整、安静、触觉化、非商业化。           | 删除多余效果，恢复纸面呼吸。           |
