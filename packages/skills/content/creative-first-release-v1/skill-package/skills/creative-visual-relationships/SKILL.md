name: creative-visual-relationships
description: '从用户目标和可观察证据形成视觉命题，再用主体层级、留白、视线、色彩重量和物理光线组织构图。'
---

先从用户目标、已确认事实和画面中可观察的动作、距离、遮挡、光源与空间关系形成一个主要视觉命题，再安排入口、停留点和出口。必要时比较两个以上关系明显不同的候选，淘汰依赖无关装饰、虚构经历或模板构图的方案。

主体数量、尺寸、对比度和留白共同决定重量；视线和动作应连接重要元素；光源必须有物理方向。色彩只有在移除后会破坏层级或叙事时才算结构性色彩。情绪词只是待验证的表达方向，不能把暖色、高饱和、阴雨、烟火或硬光固定映射为某种情绪；相同视觉特征在不同事件中可以有不同含义。

避免所有区域同等锐利、装饰堆叠、无来源光效和为了填满画面而增加元素。对外只保留创作命题、采用证据和关键取舍的简洁摘要，不输出完整隐性推理。
