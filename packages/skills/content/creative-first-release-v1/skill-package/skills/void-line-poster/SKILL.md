# 虚空线稿 · 实验艺术书籍版画海报

## 一、目标与画幅

每张照片制作一张独立海报，不将多张照片拼成一张。整体默认 3:4 竖版，上下高度严格 1:1，各占画面的 50%。上半区是真实摄影，下半区是从这张照片重构的超现实极简版画，两者形成摄影与艺术解释的对照，而非照片加滤镜或完整场景复刻。

## 二、保留摄影

上半区保留原照片的主结构、真实质感、自然光线与阴影，以及现有色彩氛围。原片若已有成熟后期和清楚的光色层次，直接保留；确有必要时才做细微的摄影色彩调整，不为艺术杂志或展览摄影的感觉重复套色。不把照片插画化，也不在摄影区覆盖线场、网点或纸纤维。

先辨别原片的光线意图：夜景、逆光剪影和高调画面不等于曝光错误，也不必把明暗拉向中间灰。若意外欠曝或过曝使主体、面部或重要动作不可读，只做克制的局部暗部、高光与白平衡调整，保留主光方向、环境气氛和亮部层次；不把摄影区整体提亮成平光、套重 HDR 或凭空补出原片没有的细节。

确需调整时，先圈定可见问题和受影响部位，只改变该处的光色；未受影响的肤色、衣物或物体固有色、材质纹理及背景光色保持原片关系，不用统一滤镜顺带改掉整张摄影区。

适配 3:2 横幅时自然取景，优先保留主体和有意义的动作关系。需要时可自然延伸天空、地面或环境背景，但不拉伸、扭曲、重塑或改变主体。环境延伸衔接原有光影和空间，不用新增角色改变照片的故事。若用户要求原片像素完全不变，应采用能锁定原片的排版或合成方式；提示词本身不能保证生成式工具的逐像素保真。

## 三、读取主题与关系

从当前照片提取最易识别的**主题、轮廓、姿态和叙事关系**。观察动作与方向、光影的走向、主体之间的距离，以及主体与环境的空间关系，决定哪一项最值得在下半区被放大。

最显眼的颜色或最大的物体不一定是叙事核心。小人物、动物或结构若承担动作、方向与尺度，就保留其可辨识的姿态和关系；多个对象共同构成一个动作时，可把它们作为一个视觉整体，不因“一个主体”而删掉故事的另一半。没有角色的照片从本来的形态与空间提炼，不强加人物或通用图标。

## 四、重构极简版画与动态场

将主体压缩成清晰克制的视觉锚点，通常以较小尺度置于广阔负空间，只保留最基本而有辨识度的轮廓和姿势，不复制复杂细节。位置与尺度由这张照片的表达决定，不固定居中、偏心或沿地平线排布。

把原作中的**动作、方向、光影或空间关系转化为围绕主体展开的动态场**。动态场自然选择一种主要运动逻辑，基于主体自身的特性：可以从上方向下降、垂直上升、沿特定方向流动、从核心扩散，或形成不规则涟漪与回声。这些是开放的可能性，不是按题材套用的清单；静态关系也可以通过间距、悬停和回声呈现，不必伪造主体在移动。

使用丰富的细线、破碎轨迹、粗糙半色调点与粒子密度变化表达运动。核心附近更密集、更强烈，边缘逐渐稀疏、碎片化，并消失在负空间中。锚点与动态场互相解释，让线的走向、转折和密度承接这张照片的特征，而不是给小图标铺一层装饰纹理。

避免同时叠加多个效果。让**一个主体、一个动作、一个庞大的空间关系**成为画面核心；共同承担这一关系的元素仍是一个整体。保留广阔而连续的负空间，让它成为运动、距离和尺度的一部分，不用均匀撒点填满纸面。

## 五、照片主色与印刷语言

从上方照片汲取**最具辨识度、最鲜艳的主色**，结合暖白、象牙白或自然纸质色调，以及极简黑色，形成严格的 2–3 色系统。主色可适度净化和增强，使其鲜艳有力而不过于数字化；黑白照片或用户明确不要加色时，沿用其黑白关系。

层次来自半色调密度、墨水叠加与纸张负空间，而非普通渐变。保留丝网印刷、Risograph、粗颗粒、纸纤维、墨水覆盖不均与轻微套印错位的印刷感；这些质感服务主体与动态场，不形成多个竞争焦点。印刷语言只进入下半区，避免 CG、3D、逼真光影与流畅的数字插画氛围。

## 六、实验艺术书籍微型排版

从照片的动作、距离、状态、情绪或隐喻中提取一个**非常简短的英文标题**，搭配 **2–4 个微文本元素**。微文本可自由组合短语、状态词、位置或对象信息、序列号、坐标式数字、方向词、档案标签或观察笔记，形成克制的实验性艺术书籍排版。

文本可以沿地平线、动态轨迹、主体轴或负空间边缘对齐，也可以垂直设置、旋转、间隔、嵌入粒子场，或轻微穿透线条。让布局本身参与空间和运动，而非独立浮在图像上；不是每张都做两行、统一角标或固定位置。

字号与层级保持微型而清楚，标题和微文本不抢主体，英文拼写准确。序列号、坐标式数字与档案标签可以是版面设计符号，不把编造的数据声称为真实拍摄地点、日期、机构档案或个人信息。用户指定文字时采用其内容；明确无文字、纯图或限定两行时，以用户要求为准。不添加署名或水印。

## 七、成图后的质量检查与修改

有成图后再检查：每张照片是否独立输出，3:4 与上下等分是否成立，摄影是否保留真实主体和光影、关键部位是否可读且没有无故压暗或泛白；下半区的锚点是否仍可辨识，动态场是否承接原作的动作或空间，是否只有一种主导运动逻辑；主色是否来自照片，2–3 色与印刷感是否清晰，负空间是否仍然广阔；标题与微文本是否准确并参与构图。

效果不理想时针对可见问题修改：锚点失去身份，恢复关键轮廓或姿态；线场只是装饰，重组它与主体的方向或距离；多个效果争抢，留下一个主运动；纸面太满，减少边缘粒子和无作用轨迹；数字感太强，改用网点、墨层与纸白；文字僵硬，调整其与轨迹、轴线或空白的联系，而不是继续添加标签。每轮优先处理最影响表达的一处，保留已经成立的部分。
