# 实景转译·日常记忆页

把一张普通照片转成一件**轻而具体的生活记忆页**。这不是图像修复、滤镜，也不是把任何照片缩小贴到白纸上。摄影提供一个生活证据；纸面、局部重绘与留白把它变成一次被选择过的回忆。

每张图只建立五件事：**一个记忆证据、一个生活关系、一处小型重绘场、一块有作用的空场、一种主材料行为**。若加入颜色、文字或拼贴痕迹，它们必须让其中至少一项更强；否则删除。

## 2. 选择模式

先确认用户需要“记忆感”还是“可辨识性”。不要对人、宠物、产品或文化物件擅自改变身份。

| 模式                 | 何时使用                                                               | 必须保留                                          | 可改变的内容                                 |
| -------------------- | ---------------------------------------------------------------------- | ------------------------------------------------- | -------------------------------------------- |
| **记忆重绘**（默认） | 随手拍、旧物、旅行、食物、街角、窗景、局部风景，用户重视气氛和再叙述。 | 一个主体或空间证据、一个动作/关系、一个感官印象。 | 景深、局部位置、背景细节、比例、绘制语言。   |
| **保真轻绘**         | 人物、宠物、品牌产品、建筑特征、传统器物或用户明确要求“认得出来”。     | 身份、姿态、关键轮廓、配色、独特标志与主要透视。  | 背景噪点、次要道具、局部色彩密度和纸面空场。 |

不承诺去噪、补脸、超分辨、破损修复、上色复原或像素级还原。这些是不同类型的图像处理任务。

## 3. 读图：从照片选出一个生活片段

在内部建立一个简短 Memory Card，不向用户展示。

| 要素     | 必须回答的问题                                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 记忆证据 | 这张照片最不可替代的一个主体、局部或空间事实是什么？例如猫蜷起的姿态、车窗雨痕、一碗食物的蒸汽、旧门的颜色、某人回头的瞬间。 |
| 生活关系 | 只选一个关系：靠近、等待、穿过、停留、遮挡、照亮、散开、重复、倚靠、远望或移动。                                             |
| 感官线索 | 光、温度、湿度、材质、声音或时间中，哪一个能通过色彩、边缘或空场被看见？                                                     |
| 识别要求 | 需要保留主体身份、文字、产品标识、建筑特征或文化物件吗？若需要，切换为保真轻绘。                                             |
| 主空场   | 空场在托住、拉远、围住、压低、隔开还是让主体显得脆弱？不能只写“留白多”。                                                     |
| 删除清单 | 至少删除三类内容：杂物、重复背景、招牌、路人、枝叶、噪点、地面纹理、复杂天空或不服务关系的道具。                             |

写出一句可见命题：

`让 [记忆证据] 在 [纸面空场] 中因 [生活关系] 而显得 [可见后果]，以 [感官线索] 留住这个时刻。`

例如：`让靠窗蜷着的猫在冷白纸面的下侧显得被午后光托住，以一小片浅金色被子留住温度。` “治愈、诗意、文艺、高级”不是有效命题。

## 4. 背景与留白：先做空间，再画主体

背景应是无边框、无相纸、无渐变、无满版纹理的哑光纸面。默认自然白；仅在源图光温或情绪需要时选择冷白、暖白、浅灰、浅砂或极淡的雾色。不得自动生成旧黄纸、复古脏污、密集纸纹或手账底图。

| 构图等级     | 适合的照片                                                     | 重绘场占画面 | 连续空场占画面 | 空场的工作                           |
| ------------ | -------------------------------------------------------------- | -----------: | -------------: | ------------------------------------ |
| **微型记忆** | 单物、小动物、远景小人、窗影、路牌、局部静物、旅行碎片。       |        8–18% |         72–88% | 制造孤立、安静、轻微距离或被记录感。 |
| **场景素描** | 车辆、宠物、室内一角、小店、建筑、两三个物体、可读的环境关系。 |       18–35% |         55–72% | 留出呼吸，同时让主体和环境仍然可辨。 |
| **亲近片段** | 人物近景、亲密互动、复杂物件、文化器物或用户要求保真。         |       35–48% |         40–58% | 以留白隔绝杂讯，而不让主体失去身份。 |

先选构图等级，再决定留白。不要将“主体 10–16%、留白 80–88%”硬用于所有题材；人物、猫、车辆、室内和建筑常需要更大的重绘场才能保持真实关系。

将重绘场偏离几何中心，优先放在下三分之一、左右一侧或源图动作的起点/终点。空场必须形成**一整块连续区域**，而不是被彩点、贴纸、云朵、日期和小图案切碎。

## 5. 局部重绘：保留一个证据，不复述所有细节

重绘场是所有颜色与细节最集中的区域。它需要保留一个明确的生活证据和最多两组从属信息；它不应变成一张缩小的完整照片。

| 源图内容                   | 应提取的证据                                              | 常见删减                                             |
| -------------------------- | --------------------------------------------------------- | ---------------------------------------------------- |
| 人物 / 宠物                | 姿态、面部识别锚点、衣物/毛色关系、一件与动作有关的物品。 | 大段无关背景、第二人物、过度磨皮、夸张大眼与卡通化。 |
| 食物 / 日常物件 / 产品     | 轮廓、材料、使用痕迹、台面/手的接触关系。                 | 整齐道具、广告包装、无关餐具和商业促销排版。         |
| 旅行 / 街角 / 建筑         | 独有的入口、转角、窗、招牌轮廓、道路方向或光影。          | 天际线细节、重复窗格、人群、复杂车辆和旅游元素。     |
| 风景 / 天气 / 植物         | 一条边界、一处光、一段路径、一个前景证据。                | 逐片树叶、完整云层、每一座山、装饰性鸟和默认日轮。   |
| 传统文化 / 手作 / 地方物件 | 真实材料、使用动作、纹样/结构中的一项特征。               | 自动加书法、印章、灯笼、龙凤、祥云和泛化国潮配色。   |

允许主体边缘自然失焦、被轻微干刷吞没或向纸面退去，但不得留下数码矩形遮罩、贴纸白边、厚纸投影或“照片蒙了一层水彩滤镜”的效果。

## 6. 色彩、材料与可选文字

### 6.1 色彩

先用明暗和纸面空场建立层级，再提取两到四种来自原图的综合色。只允许一处颜色成为视觉支点；它通常占完整画面的 **2–12%**，只用于保留温度、光源、衣物、食物、花朵、招牌或另一个源生事实。色彩不得扩散进主空场，也不得被换成默认糖果色、复古红蓝黄或泛化胶片色。

### 6.2 材料

每张图只选择一种主材料行为，并在需要时加一种从属痕迹。

| 主材料行为      | 可见效果                           | 最适用的生活感                       |
| --------------- | ---------------------------------- | ------------------------------------ |
| 铅笔 / 彩铅线描 | 轻线、擦改、有限阴影。             | 观察、私密、安静、旧物。             |
| 淡水彩          | 透明色块、边缘停留、轻微晕开。     | 光、湿度、食物、皮肤、花或天气。     |
| 干性蜡笔 / 粉笔 | 粗颗粒、哑光压实色面。             | 温度、儿童感、墙面、织物、烟火气。   |
| 纸擦 / 干刷     | 不完整边缘、纸面显露、轻微移动感。 | 风、影子、路面、旧店、行走。         |
| 低密度转印      | 断续摄影颗粒与局部真实细节。       | 旅行、档案感、玻璃、车窗、地方记忆。 |

不得同时堆叠铅笔、水彩、干刷、蜡笔、网点、胶带、撕边和印章，以免变成手账拼贴。

### 6.3 文字

默认无文字。只有用户明确要求显示文字并提供准确文案时，才可使用不超过两行的小尺寸中文或英文，置于连续空场的边缘，作为停顿而不是标题。不得擅自编诗、翻译、加日期、field note、地点、签名、作者名、Logo、印章或乱码。

## 7. 把决定写成画面指令

把当前照片的模式、完整画面、背景空场、记忆证据、生活关系、颜色、材料和删除项写成一段清晰的图像指令。顺序和篇幅可以根据画面决定，不必套用固定段数或字符范围；不要以“诗意手绘、废片焕新、治愈感”代替位置、比例、轮廓、颜色和删减。

画面指令应能回答：**哪个细节让它只属于这张照片？空场为什么存在？颜色在哪里结束？手绘材料为何必要？** 它必须描述一张完整纸本插画，而不是照片滤镜、原图并列或保留照片窗口。

## 8. 质量门与定向修改

生成前检查 Prompt；用户提供成图后，再使用下表判断。未通过时只修复一个观察到的问题。

| 质量判断                                                                           | 未通过时的定向修正                                                                |
| ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 成图被读作完整的记忆页插画，而非照片滤镜、证件修图或相纸贴在白底上。               | 移除摄影窗口与矩形边缘，重申“重新绘制”以及纸面与主体的一体性。                    |
| 主体/场景仍保留最关键的生活证据；保真需求没有被破坏。                              | 恢复身份锚点、姿态、独有结构或颜色关系，不增加背景细节。                          |
| 留白有明确方向和心理作用，且未被无关装饰切碎。                                     | 指定连续空场的方位、比例、边界与托住/拉远/隔开作用。                              |
| 重绘场面积与照片复杂度相称；小主体没有失去可读性。                                 | 在三档构图等级间调整，而不是机械压回 10–16%。                                     |
| 缩略图中仍能读到一项闭合轮廓、身体姿态、物件接触或明确方向；空场没有吞没记忆证据。 | 放大重绘场或减少细节，将证据收束为更强的单一轮廓/方向；不要用额外颜色和纹理补救。 |
| 色彩只集中在重绘场，且有来源；空场仍然安静。                                       | 降低/删除扩散色彩，只保留一个源生色彩支点。                                       |
| 只出现一种主材料过程；画面没有变成手账、儿童贴纸或复古海报。                       | 删除胶带、网点、厚阴影、撕边、标签和多余材料效果。                                |
| 文字仅在用户明确要求、且准确时出现，不与插画争夺中心。                             | 移除未授权文字；需文字时缩小并采用用户批准的精确文案。                            |
| 删除项确实离开画面，没有以淡影、背景纹样或小图标回流。                             | 重新列出删除项，合并细节，并保持空场连续。                                        |

## 9. 通用 Golden Eval

在将 Skill 视为稳定前，至少分别测试以下类别。每张都应在“生活证据、空场功能、主体可读性、色彩局部性、材料单一性、没有装饰余项”六项上通过。

| 测试照片                 | 主要验收点                                                 |
| ------------------------ | ---------------------------------------------------------- |
| 宠物或人物生活照         | 身份/姿态可认，且留白不使主体变成泛化卡通。                |
| 食物、器物或产品         | 物体材料和使用关系清楚，没有转成商业海报。                 |
| 室内、旧店或建筑细节     | 入口、窗、光或结构关系可读，背景杂物已被主动删除。         |
| 街角、车窗或旅行随拍     | 保留独有方向/时刻，不生成可套用的旅游模板。                |
| 自然、天气或小景         | 只保留一段边界、光或前景证据，不自动生成山水、日轮或飞鸟。 |
| 手作、民俗或地方文化物件 | 保留真实材料/行为，不添加国潮符号和虚构文字。              |

## 10. 硬性避免项

避免承诺或伪装照片修复、超分辨、补脸、上色复原、像素级还原；原图照片残留、矩形照片框、前后对照排版；无功能白底、满版纸纹、旧黄纸；复杂照片缩小后原样贴上；主体过小而不可读；自动日轮、飞鸟、树、花、月亮、诗句、日期或 field note；无来源色彩；撕纸花边、胶带、相纸阴影、贴纸白边、厚纸层、网点、手账、儿童贴画、复古广告；水墨、国风符号、霓虹、3D、电影光效、AI 磨皮；Logo、CTA、水印、签名、地点和乱码文本。
