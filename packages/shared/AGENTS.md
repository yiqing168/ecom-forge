# Shared 包说明

- 本包只放确定性、无副作用工具，例如 canonical hash、幂等辅助、错误码和成本公式。
- 不访问 DB、Redis、Provider、文件系统或环境变量，不持有进程级可变真相。
- 同一结构化输入必须产生稳定输出；对象规范化需定义 key 排序、空值、数字和数组语义。
- 不在 shared 中堆放仅单模块使用的工具，避免形成全局杂物包。
- 每个公共函数至少覆盖正常、边界和非法输入测试。
- 金额工具只接收和返回十进制字符串，内部统一使用 `decimal.js`；禁止导出 Decimal 实例或接受 `number`。
- 金额统一保留 2 位小数并使用 `ROUND_HALF_UP`，业务包不得自行实现舍入、算术或比较。
